# English Thinking System

一个面向英语零基础/低基础学习者与儿童的英语思维学习系统。

核心学习路径：

> 真实世界 / 核心画面 → 英语底层逻辑 → 含义自然生长 → 场景应用 → 知识连接 → 主动输出

本仓库是项目的唯一主仓库。项目规则以 `PROJECT_MASTER.md` 为最高级别总控文档，阶段规划见 `ROADMAP.md`。

## 核心模块

- 英语思维 Skill
- 850 核心词知识库
- 三层学习机制：快速理解 / 深度学习 / 知识网络
- 词根词缀辅助系统
- 3D 知识图卡系统（统一沿用 BE 动词 3D 图卡模型）
- 知识图谱 / 思维导图系统
- 170 天学习路径与复习机制
- Web 学习产品
