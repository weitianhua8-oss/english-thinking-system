# English Thinking System｜英语思维 850

一个面向英语零基础、低基础学习者与儿童的英语思维学习系统。

核心学习路径：

> 真实世界 / 核心画面 → 英语底层逻辑 → 含义自然生长 → 场景应用 → 知识连接 → 主动输出

项目总控规则以 [PROJECT_MASTER.md](PROJECT_MASTER.md) 为准，阶段优先级见 [ROADMAP.md](ROADMAP.md)。GitHub 是项目的唯一可信版本源。

## 当前真实状态

- 850 个母词已完整入库：S 级 80、A 级 200、B 级 570。
- 170 天 × 每天 5 词学习计划已完成。
- Level 1 的 50 个骨架词已完成深度课程，并提供可离线打开的学习网站。
- V2 三层学习与知识网络目前在独立开发分支中；不应被表述为已覆盖全部 850 词。
- 3D 图卡已有生产规范、图卡提炼和独立试验分支；实际批量资产的完成情况以路线图和分支记录为准。

详细现状与产品边界见 [docs/10_项目现状与后续安排交接.md](docs/10_项目现状与后续安排交接.md)（合流后由本地项目带入）。

## 核心模块

- 英语思维内容 Skill
- 850 核心词知识库
- 三层学习机制：快速理解 / 深度学习 / 知识网络
- 3D 知识图卡系统（采用 BE 动词图卡视觉基准，不使用固定角色）
- 知识图谱 / 思维导图系统
- 170 天学习路径、学习反馈与间隔复习
- 离线 Web 学习产品
