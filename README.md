# 英语思维850｜V1 完整项目

这是「英语思维学英语」的第一版完整产品闭环。

## 产品核心
不是把 850 个词翻译成中文，而是用：
**核心画面 → 底层逻辑 → 关系网络 → 高频表达 → 3D知识图卡 → 间隔复习**
逐步建立英语世界模型。

## 当前交付
- 850 个词完整母词库（0 重复）
- S/A/B 分级与五级学习阶段
- 170 天 × 每天 5 词学习计划
- Level 1：50 个骨架词完整标准化教程
- Level 1：3D 知识图卡生产清单
- 内容 Skill、图卡 Skill、学习机制、质检 SOP、网站 IA
- 离线可打开的 V1 学习网站

## 目录
- `data/`：850 词与学习计划数据
- `content/`：课程正文
- `prompts/`：3D 图卡生产规范
- `docs/`：产品与内容规范
- `website/`：离线网站原型
