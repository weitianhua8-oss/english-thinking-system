# Project Starter Template

复制本目录到新项目根目录后，先填写六份文档，再开始 T3 及以上开发。

```text
PROJECT.md       项目使命与不可变边界
PRD.md           当前产品版本与验收
ARCHITECTURE.md  系统组成、数据和运行方式
RULES.md         必须做与绝对禁止事项
DECISIONS.md     可追溯的关键取舍
PROGRESS.md      当前真实进度、下一步与风险
```

启动顺序：Owner 描述目标 → 判定 T1–T5 → 写任务卡 → T3+ 先写计划 → Build/Test/Review → Owner 验收 → Commit → LEARN。

模板中的方括号必须替换；没有信息时写“尚未决定”和补齐责任人，不能伪造完成状态。
