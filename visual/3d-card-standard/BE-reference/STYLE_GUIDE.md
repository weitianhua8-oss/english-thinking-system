# BE 3D Knowledge Card — Canonical Visual Standard

## Reference
Canonical source asset: `BE动词：连接身份、位置与状态.png` recovered from the ChatGPT file library.

This document freezes the visual language extracted from that approved reference. The original PNG should be added to this folder when binary repository upload is available.

## Core teaching metaphor
BE is visualized as a **bridge / connector** between the subject and the information that locates the subject in a condition.

Primary semantic flow:

`主语 → BE → 主语现在处于什么情况`

The bridge metaphor must remain visually dominant. BE is not shown as an action engine; it is shown as a connector that carries the subject toward identity, location or state information.

## Canvas and framing
- Square educational knowledge-card composition.
- Warm off-white / cream background.
- Thick rounded outer frame with soft 3D depth and a subtle gold/cream edge.
- Generous internal padding; content never touches the frame.
- Overall feel: clean, soft, tactile, child-friendly 3D educational infographic.

## 3D rendering language
- Soft clay/toy-like 3D rendering.
- Rounded geometry; avoid sharp futuristic hard-surface design.
- Soft diffuse light, gentle ambient shadows and mild highlights.
- Materials should feel matte to semi-matte, not metallic/glossy.
- Objects can include miniature scenery, buildings, furniture, nature and generic people when useful to explain a scene.
- No fixed character/IP system. People are illustrative scene elements only and must not become recurring branded protagonists.

## Typography hierarchy
1. **Main title**: very large, bold, dark navy, high contrast.
2. **Core-definition banner**: short, centered, dark text on a warm cream/yellow rounded pill or panel.
3. **Central relationship formula**: large dark text inside a blue-framed rounded 3D panel.
4. **Section headers**: bold white or dark text on saturated rounded header tabs.
5. **Examples**: medium-size dark text, centered or neatly wrapped.
6. **Bottom takeaway**: large bold summary inside a warm rounded footer banner.

Text must be short enough to read at a glance. Do not use long paragraphs inside the image.

## Main composition
### Top zone — concept definition
- Large title: `BE 动词 ①｜状态连接器`.
- Immediately below: one-line source logic: `BE = 存在 / 处于 / 把主语连接到某个状态或信息`.
- Then a simple relationship formula: `主语 → BE → 现在处于什么情况`.

### Middle zone — dominant spatial metaphor
- A large 3D bridge occupies the visual center.
- The bridge is labeled prominently with `BE`.
- Subject is positioned on one side / origin platform.
- Flow paths move from the bridge toward the semantic destinations.
- Use luminous or clearly colored connector paths/arrows to make branching relationships instantly visible.
- A short metaphor banner may sit below the bridge: `BE 像一座桥，不是动作发动机`.

### Lower zone — semantic branches
Use three side-by-side cards, each with a distinct accent family and one clear concept:

1. **身份：是什么**
   - Example pattern: `I am a student. / She is a doctor.`
   - Formula: `主语 + be + 名词`
   - Visual scene: generic identity/role examples.

2. **位置：在哪里**
   - Example pattern: `The cat is on the sofa. / They are at school.`
   - Emphasize that `on / at / in` supplies the location while BE connects the subject to it.
   - Visual scene: sofa/cat, school/building or similar spatial cue.

3. **状态 / 特征：什么样**
   - Example pattern: `You are happy. / He is tall. / It is cold.`
   - Formula: `主语 + be + 形容词`
   - Visual scene: emotion, height, temperature or other visible state cue.

### Bottom zone — final takeaway
A single strong summary across the width:

`身份、位置、状态：本质都是主语所处的情况。`

## Color-system behavior
- Main structural color: blue for BE / connector / bridge system.
- Semantic branches use clearly differentiated accent families rather than one monotone palette.
- Warm cream/gold is used for framing and high-level explanation banners.
- Accent colors should be soft but saturated enough to create hierarchy.
- Avoid dark backgrounds, neon cyberpunk palettes or heavy gradients that undermine readability.

## Spatial and connector rules
- Relationships must be visible spatially, not explained only through text.
- Use arrows, paths, branching light trails or physical structures when a relation grows from one core idea into several uses.
- Direction should match semantic logic: source/core concept first, extensions later.
- Do not create decorative connector lines with no semantic role.

## Information-density rule
The reference is information-rich but segmented. Reproduce that logic:
- one concept per card/module;
- short text blocks;
- obvious whitespace between modules;
- large visual metaphor in the center;
- examples remain secondary to the core image.

## Image-generation rule
Before generating any English 3D knowledge card:
1. Run the English Thinking Skill.
2. Identify the single core image / underlying logic.
3. Decide whether bridge, container, path, surface, point, direction, contact, separation, transfer or state-change is the best spatial metaphor.
4. Build the visual around that metaphor.
5. Only then add examples and labels.

Never begin with a decorative scene and force the knowledge into it afterward.

## What must stay consistent with BE reference
- warm cream framed card
- soft rounded 3D infographic language
- navy high-contrast title text
- central large semantic metaphor
- modular lower explanation cards
- spatial arrows/paths with actual semantic meaning
- short formula + example + visual scene combination
- strong one-line takeaway at the bottom

## What may vary by knowledge point
- central metaphor object (bridge, target, container, path, surface, hand/action, etc.)
- number of semantic branches
- branch accent colors
- supporting props / generic people / objects
- exact example sentences
- labels and formulas

## Prohibited drift
Do not turn this system into:
- a fixed cartoon-character/IP learning system;
- flat textbook diagrams with no spatial teaching metaphor;
- dense poster pages dominated by paragraphs;
- cyberpunk / metallic / dark 3D art;
- decorative 3D scenes whose objects do not encode the concept;
- inconsistent one-off styles for each vocabulary item;
- a Chinese-translation list presented as an infographic.

## Semantic note from the BE source
The BE model should preserve the conceptual conclusion:
- BE is not merely equivalent to Chinese `是`.
- BE expresses existence / being in a condition and connects the subject to identity, location, feature or state information.
- A useful learning hook is `BE = 处于` rather than forcing every use into `是`.
