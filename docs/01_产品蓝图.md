# 产品蓝图

## 1. 产品一句话
**英语思维850 = 用 850 个高频词，建立小白的第一套英语“世界模型”。**

## 2. 用户不是在背什么
不是：
`get = 得到 / 获得 / 到达 / 变得 / 理解`

而是：
`get = 经过过程 → 最终触达到目标`

再从目标类型自然长出具体用法。

## 3. 五层课程
- Level 1｜50 骨架词：建立人物、动作、空间、感知、逻辑底层坐标。
- Level 2｜累计150 生存词：能处理基础日常场景。
- Level 3｜累计300 日常核心词：形成基础表达网络。
- Level 4｜累计500 基础表达词：扩大状态、关系、生活场景。
- Level 5｜累计850 核心词：形成完整小白基础词网。

## 4. 三种词级
- **S级 80**：完整英语思维 Skill + 多张 3D 图卡 + 易混对比。
- **A级 200**：标准 Skill + 1 张标准图卡，必要时加对比卡。
- **B级 570**：场景化精简 Skill + 主题图板，不追求过度解释。

## 5. 一词三层
1. 知识地图：它在哪里？
2. 英语思维正文：它为什么这么用？
3. 3D 图卡：如何一眼看懂并复习？

## 6. 产品闭环
学新词 → 看核心画面 → 理解底层逻辑 → 看关系卡 → 做最小输出 → 进入复习队列 → 回到知识树。

## 7. V1 成功标准
- 用户不用中文释义也能复述核心画面。
- 用户能解释至少一组易混词的“画面差异”。
- 用户能把动作词和空间词重新组合，而不是死背短语。
- 用户知道自己学到知识树的哪一个节点。
