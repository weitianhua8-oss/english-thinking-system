# English Thinking Teaching OS V2.0

> Governance: [PROJECT_OS.md](../PROJECT_OS.md) is the highest project policy. This document is the single canonical source for the teaching architecture; [PROJECT_MASTER.md](../PROJECT_MASTER.md) summarizes it and [ROADMAP.md](../ROADMAP.md) schedules its adoption.

## 1. Teaching outcome

English ability is the capacity to move from reality to an English scene, select a focus and relationship, understand how meaning grows, decode input, create an expression, connect knowledge, and retain it for later use.

The guiding proposition is **Language ≠ Translation**. Chinese can be an explanatory bridge, but it is not the learner’s target storage or production route.

## 2. The mother architecture

`WORLD → SEE → FOCUS → GROW → READ → CREATE → CONNECT → REVIEW`

The compact learning spine is **SEE → FOCUS → GROW → READ → CREATE**. `WORLD` establishes the worldview; `CONNECT` enables transfer; `REVIEW` protects long-term access. These are one loop, not eight isolated courses.

| Stage | Learner question | Learning operation | Main evidence |
| --- | --- | --- | --- |
| WORLD | “English is looking at what?” | Notice how languages choose different information focus from the same reality. | Can describe a scene without translating word by word. |
| SEE | “What is happening?” | Reconstruct a concrete person, object, action, state, path, or space. | Can point to or describe the core image. |
| FOCUS | “What does this sentence put in view?” | Select the focal entity, action/state, relation, and information order. | Can explain a sentence camera. |
| GROW | “Why can this word or structure say that?” | Extend from one core image and logic to high-frequency uses. | Can trace a use back to the core model. |
| READ | “What scene does this input rebuild?” | Decode listening or reading from clues back to scene, focus, and relation. | Can recover meaning without translating every word. |
| CREATE | “How do I show this scene in English?” | Build a minimal, accurate sentence from the selected camera. | Can say/write an appropriate expression. |
| CONNECT | “What else shares, contrasts, or extends this relation?” | Link real semantic, grammar, scene, and contrast relationships. | Can choose a useful connection and explain it. |
| REVIEW | “Can I still use it when the cue returns later?” | Diagnose demonstrated mastery and schedule the next retrieval opportunity. | Later retrieval and use remain accurate. |

## 3. Module responsibility and boundary

| Module | Primary responsibility | Must do | Must not become |
| --- | --- | --- | --- |
| Culture | `WORLD` entry: reveal different cultural attention, categorization, and expression habits. | Create a worldview that supports Language ≠ Translation. | An isolated culture-facts course or a mandatory detour before every word. |
| Grammar Camera | `FOCUS` engine: make sentence focus, viewpoint, relation, order, and background visible. | Help learners choose what is central, then expand outward. | Grammar-label memorization or a replacement for meaning. |
| Word Image Pro | `SEE + GROW` learner-facing component. | Make one core image, one-sentence logic, meaning growth, and contrast visible. | A decorative picture, a translation card, or an independent vocabulary curriculum. |
| 3D Knowledge Card | Supporting visual asset for `SEE`, `FOCUS`, and `GROW`. | Spatialize one validated concept or relation after the teaching logic is clear. | A visual source of truth, a fixed-character system, or decoration that arrives before meaning. |
| Sentence | `CREATE` practice layer. | Turn a seen scene and camera into minimal, correct, natural output. | Chinese-template translation drills or grammar exercises detached from a scene. |
| Sound Layer | Cross-stage auditory layer, especially `SEE`, `READ`, and `CREATE`. | Link sound, rhythm, stress, and listening cues to the same scene and expression. | A stand-alone pronunciation score that ignores meaning and output. |
| Knowledge Network | `CONNECT` transfer engine. | Show explainable left-to-right semantic, contrast, scene, and grammar relationships. | A Simple Mind Map, a tree built for appearance, or links without learner-visible reasons. |
| 850 Vocabulary Foundation | Content-coverage inventory. | Supply staged, reusable high-frequency materials as `S80 / A200 / B570`. | A proxy for thinking ability or a promise that all 850 require equal depth. |
| Mastery-driven Review | `REVIEW` memory engine. | Use observed mastery to select retrieval and review depth; allow learner-controlled new-word load. | Fixed-date repetition presented as proof of learning. |

### Meaning First → Grammar Name Later

Every relevant lesson should first establish the scene, camera, and relationship. A grammar name may be introduced after the learner can usefully point to what it names. The name supports communication and reuse; it does not replace understanding.

## 4. Thinking Ability Ladder (C0–C5)

The ladder measures transferable thinking ability, not the number of words completed. A learner may cover 500 words while still working at C2 in a new relation, or show C4 transfer with a small but well-connected vocabulary.

| Level | Ability | Observable evidence |
| --- | --- | --- |
| C0 · Recognition | Notices an English item but relies on a translation or prompt. | Can identify a familiar word/card with support. |
| C1 · Scene | Recovers a core image or basic situation. | Can describe what is happening in a familiar scene. |
| C2 · Focus | Selects the focal entity/action/relation and distinguishes a nearby alternative. | Can explain why `in`, `on`, or `at` changes the picture. |
| C3 · Growth | Explains a new high-frequency use through one coherent core model. | Can connect an unfamiliar use back to the word image and logic. |
| C4 · Creation | Produces a suitable minimal sentence from a scene without translating first. | Can speak or write an accurate expression and repair it after feedback. |
| C5 · Transfer | Applies the model to new input, new combinations, or a new context. | Can decode, choose, and explain an appropriate expression beyond memorized examples. |

### Coverage remains separate

`50 / 150 / 300 / 500 / 850` indicates how much of the 850 Vocabulary Foundation has been encountered. `S80 / A200 / B570` indicates content-production depth. Neither number replaces C0–C5 assessment.

## 5. Six-dimensional mastery model

Mastery is a profile, not one score. Record the six dimensions independently where the product and content support evidence; do not infer a high dimension merely because another is high.

| Dimension | Question | Minimum evidence |
| --- | --- | --- |
| SEE | Can the learner recover the core image/scene? | Points to, selects, or describes the correct scene. |
| HEAR | Can the learner recognize the sound pattern in meaningful input? | Identifies the target in a short, contextual audio cue. |
| UNDERSTAND | Can the learner explain the focus and logic? | Gives a scene-based explanation rather than a list of translations. |
| DISTINGUISH | Can the learner separate a confusable nearby choice? | Explains the image/camera difference and selects correctly. |
| CREATE | Can the learner produce a fitting expression? | Creates a minimal, correct, natural sentence from a prompt. |
| TRANSFER | Can the learner use the model outside the taught example? | Handles a new scene, combination, or input and explains the choice. |

For early learners, partial evidence is valid: an item can be strong in SEE and still need work in HEAR or CREATE. Review should target the weakest required dimension, not repeat the entire lesson mechanically.

## 6. Teaching Quality Gates (G1–G7)

Every new or materially revised teaching asset is checked in order. A failed gate blocks release at that asset’s intended depth; it is not repaired by adding more content.

| Gate | Test | Pass condition |
| --- | --- | --- |
| G1 · Truth | Is the linguistic claim accurate and bounded? | No false etymology, invented rule, or overgeneralized explanation; uncertainty is marked when needed. |
| G2 · Image | Can the learner form the intended scene? | The core image is concrete or reliably visualizable and matches the target use. |
| G3 · Logic | Does one model explain the stated uses? | Meaning growth is coherent; translations do not masquerade as the model. |
| G4 · Transfer | Does it help with a new use, contrast, or combination? | At least one justified extension, contrast, or application is available at the asset’s level. |
| G5 · Camera | Is focus and relation visible and correct? | The chosen subject/entity, action/state, path/space, and information order fit the intended English view. |
| G6 · Output | Can a learner make or choose a meaningful expression? | A proportionate output/retrieval task is possible, with a scene-based success criterion. |
| G7 · Cognitive Load | Is the lesson small enough to learn now? | Information is sequenced from core image to detail; examples reuse known material and unnecessary terminology is deferred. |

S80 normally receives the fullest evidence across all seven gates. A200 and B570 may use lighter assets, but may not bypass Truth, Image, Logic, or cognitive-load checks.

## 7. Operating rules

1. The learner chooses a sustainable new-word quantity; the default pacing is a suggestion, not a competence requirement.
2. Review is mastery-driven: evidence across the six dimensions determines whether the next activity is scene recovery, sound recognition, contrast, creation, or transfer. Time intervals are only retrieval safeguards.
3. Knowledge links must have a learner-visible reason and read left-to-right where a directional flow helps understanding.
4. Word Image Pro, Grammar Camera, Sentence, and Sound Layer must point to the same scene and relation when they are used together.
5. Content coverage and thinking ability are reported separately: for example, `Coverage: 150/850; Ability evidence: C2–C3 in current unit`.
