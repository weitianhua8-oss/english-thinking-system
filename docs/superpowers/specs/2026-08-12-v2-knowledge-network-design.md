# 英语思维 850｜V2 知识网络设计

## 目标

在不替换 V1 母词库、分级、Level 课程地图、170 天计划、Level 1 课程和本机学习进度的前提下，新增英语思维三层学习与可探索的知识网络。第一批只完成 13 个样板节点：AT、ON、IN、TO、INTO、BE、-ING、THE、IF、TOO...TO...、SEE、LOOK、WATCH。

## 非目标

- 不重写或重新生成 850 个母词。
- 不批量写浅层中文释义。
- 不改动 `data/vocabulary_850.*`、`data/learning_plan_170days.csv` 的既有字段和数据。
- 不改变 `english850_level1_progress_v1` 的存储格式或清除旧进度。
- 不把开发规则、Schema 或 Markdown 分组规则展示给学习者。

## 数据边界

新增 `website/v2-data.js`，作为 V1 数据的补充层。它只为样板节点保存解释性内容和关系，V1 的 `website/data.js` 仍是原有词库和课程数据来源。

每个节点结构为：

```js
{
  id: 'to',
  word: 'TO',
  systemId: 'space-relations',
  coreMeaning: '目标 / 终点 / 指向',
  coreImage: '从起点指向一个明确终点的箭头',
  quick: {
    origin: 'TO 把路径或注意力指向一个明确目标。',
    example: 'I go to school.',
    memoryHook: '看到 TO，就找终点。'
  },
  deep: {
    logic: '...',
    scenes: [{ title: '到地点', body: '...', example: '...' }],
    structures: ['to + 地点', 'to + 人', 'to do'],
    chineseTrap: '...',
    studyTip: '...'
  },
  relations: [
    { type: 'growth', target: 'to-place', label: 'to + 地点', explanation: 'TO 先把移动指向目的地。' },
    { type: 'combination', target: 'into', label: 'IN + TO → INTO', explanation: 'IN 给出内部边界，TO 给出朝向该内部的运动。' },
    { type: 'contrast', target: 'at', label: 'TO vs AT', explanation: 'TO 是朝向终点；AT 是已定位在点位。' }
  ]
}
```

`relations` 是唯一的网络连接来源。每条边必须有 `type`、目标、学习者可见标签与一句中文解释；没有解释时不得渲染和不得写入数据。

仅支持四类关系：

| type | 含义 | 允许示例 |
| --- | --- | --- |
| `system` | 上位认知系统 | TO 属于空间与关系 |
| `growth` | 从本源直接长出的结构 | TO → to + 地点 |
| `combination` | 两个结构组合的新意义 | IN + TO → INTO |
| `contrast` | 同场景中可能选错的不同镜头 | IN ≠ INTO |

## 内容组织

学习页只由语义单元渲染，而不是将源 Markdown 的每个换行渲染成一张卡。

1. **Layer 1｜快速理解**：单词、核心意义、核心画面、简短本源、一个例句和记忆钩子。在首屏完成理解。
2. **Layer 2｜深度学习**：将核心画面、为什么、物理义到抽象义、典型场景、高频结构、例句、易混点、中式误区和学习建议，按内容关系组织为少量连续语义组。
3. **Layer 3｜知识网络**：显示所属系统及可解释关系；点击关系目标时打开目标节点并记录本次探索路径。

样板内容质量要求：每一个多义或结构用法必须用一条本源解释其生长路径；不罗列互不相干的中文释义。词源只有在直接帮助理解时出现。

## 页面与交互

### V2 课程页

保留 V1 课程与反馈按钮。对于 13 个样板节点，改为展示三层内容；其余 V1 词条继续展示原课程，避免降低已有课程质量。课程页支持回到词库和 `↑ 返回顶部`。

### 知识网络页

桌面端采用左中右三栏：

- 左：认知系统。
- 中：当前系统节点，节点同时显示单词与核心意义。
- 右：当前节点的本源、直接生长、组合关系、易混对比及解释。

点击任一关系目标时，系统自动选中目标所属系统、打开该节点、更新右侧解释，并把来源词追加到内存探索路径。探索路径用于“返回上一步”，不写入原有学习进度。

移动端不是压缩三栏：先显示系统列表，进入后显示当前词，再进入关系详情；每屏只有一个主要认知任务。中文可自然换行，例句和高频结构不能被拆散。

### 导航与兼容

导航新增“知识网络”，V1 的“知识树”保留原功能。V2 内容层未命中时，所有入口安全回退到 V1 课程页；不会中断复习、筛选、反馈或进度。

移除页面顶部的固定角色文字“诺诺”，改为不带人格设定的进度标识。

## 样板系统与连接

- 空间与关系：AT、ON、IN、TO、INTO。
- 状态与动作形态：BE、-ING、TOO...TO...。
- 条件与信息组织：THE、IF。
- 感知与注意：SEE、LOOK、WATCH。

样板关系必须覆盖至少：IN + TO → INTO、TO 与 AT、IN 与 INTO、SEE / LOOK / WATCH、BE 与 -ING、TOO + TO → TOO...TO...。每一条都在数据层存放说明，不按“同类标签”自动连线。

## 验收与迁移安全

自动化校验必须验证：

- 850 个词仍唯一，S/A/B 与 Level 1–5 仍存在，170 天计划仍为 170 天。
- 13 个样板节点均有三层必填内容。
- 每条关系只使用四种类型、目标存在、解释非空；不允许无解释连接。
- V1 localStorage 档案可解析，旧复习/反馈逻辑不变。
- 13 个样板词可从课程页打开，关系节点可跳转，未知节点安全回退。
- 长页存在返回顶部入口，手机断点下网络按逐层流程显示。

## 错误处理

V2 数据缺失、关系目标不存在或内容不完整时，不渲染该关系，并显示中性提示“该关联内容暂未开放”。任何 V2 异常都不可影响 V1 的课程、复习和进度渲染。
