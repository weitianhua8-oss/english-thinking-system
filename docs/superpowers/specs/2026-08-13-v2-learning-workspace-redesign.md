# V2 课程与知识网络工作台重构设计

## 目标

在 V2 既有数据、三层学习、可解释关系和学习反馈不变的前提下，只重构“课程学习页”和“知识网络页”的视觉框架与内容编排。页面采用清晰蓝色学习感与浅紫—浅蓝玻璃层次的融合风格，使学习者更容易从核心本源进入关系探索。

## 范围

### 重构页面

- V2 样板词的课程学习页。
- 知识网络页。

### 保持不变

- 今日学习、今日复习、词库、知识树、易混对比、学习进度页面。
- 850 词库、S/A/B、Level 1–5、170 天计划、V1 与 V2 本机进度、复习算法和 localStorage 键。
- 13 个 V2 样板词的学习内容与已人工解释的四类网络关系。
- 当前网络跳转、探索路径、返回上一步、移动端单面板步骤和返回顶部能力。

## 视觉方向

- 背景为低饱和浅紫—浅蓝渐变，作为学习工作台的环境层；不使用高对比、大面积装饰图。
- 内容区使用半透明白色面板、细边框和克制阴影，确保中文解释与例句优先可读。
- 蓝色保持主要交互含义；紫色只用于知识层级、网络与结构性强调；暖色仅用于易混提醒。
- 保留全局 `:focus-visible`、按钮语义与文字对比度，不以玻璃效果牺牲可访问性。

## 课程学习页

课程页不再把每段内容当作相同白卡，而使用语义工作台：

1. **课程抬头**：单词、核心意义、所属系统和返回词库。
2. **三层切换**：快速理解、深度学习、知识网络。一次只展开一个主层级，切换不丢失当前课程和学习反馈。
3. **快速理解**：核心画面、本源、典型例句、记忆钩子组成一个连贯首屏，而不是分散小卡。
4. **深度学习**：逻辑、场景组（标题/说明/例句一起）、高频结构、中文易错点和建议按阅读顺序分区。
5. **知识网络**：课程内显示紧凑迷你网络，包括所属系统、当前词的核心意义、直接生长、组合和对比关系。关系使用现有 `explorableRelations`；点击进入完整网络并定位当前词，不自动生成任何关系。
6. **反馈与回顶**：三种反馈按钮保留在学习页底部；长页保留 `↑ 返回顶部`。

不改变非样板 V1 课程的内容结构，避免降低现有 50 课质量。

## 知识网络页

保持当前数据驱动的左—中—右结构与探索路径，但改为有层次的地图工作台：

- **系统区**：显示可选认知系统，当前系统清晰高亮。
- **节点区**：显示单词和核心意义；当前节点是视觉焦点。
- **解释区**：依次呈现核心本源、上位系统、直接生长、组合和易混对比。每条关系保留标签、解释和“查看…”操作。
- 关系类型通过颜色与简短标记区分：生长为青绿、组合为蓝紫、对比为暖色；不依赖颜色作为唯一信息。
- 保留“打开三层课程”“返回上一步”和 `↑ 返回顶部`。

## 移动端

不把桌面玻璃三栏缩成堆叠卡。继续使用当前的步骤状态：

1. 系统；
2. 词条；
3. 关系详情。

手机端只显示当前步骤的主要面板；返回动作明确，例句、结构和中文解释自然换行。课程页三层切换改为全宽、易点按的分段控件。

## 实现边界

- 首选修改 `website/app.js`、`website/styles.css` 与 `website/app.test.js`。
- 不新增依赖、框架或远程资源。
- 新增展示内容必须来自已有 V2 节点和关系数据，并沿用 `safe`/`escapeHtml`。
- 不把 Schema、开发规则或重构说明输出到学习页面。

## 验收

- 13 个样板课程仍能完整展示三层内容、打开网络、记录反馈和进入复习。
- 非样板 V1 课程、计划、复习、进度页面行为不变。
- 网络只渲染现有已解释关系，关系跳转与返回路径不变。
- 桌面端课程与网络使用融合工作台视觉；手机端仍为单任务流程。
- 无新增横向溢出、无 inline handler、动态文本继续转义。
- 既有 59 项测试保持通过，并补充课程层切换和迷你网络渲染的回归测试。
