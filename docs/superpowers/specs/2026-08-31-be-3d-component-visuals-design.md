# BE 三模块母版：组件级 3D 配图设计

**状态：** 用户已确认

**日期：** 2026-08-31

**范围：** 仅补齐现有 BE 三模块网页知识课的 3D 场景图解；不改变教学逻辑，不扩展其他词条，不提前抽象全站 `WordLessonSpec`。

## 一、目标

当前 BE 深度学习页已具备文字、按钮、发音、匹配和判断结构，但缺少 3D 知识图卡 Skill Pro 的场景图解。孩子仍需主要依靠文字理解，尚未达到“把英语关系变成看得见的画面”的母版标准。

本轮采用“独立 3D 场景图 + 原生网页交互”的方式：

- 3D 图片负责呈现人物、物体、位置、动作过程和结果状态。
- 网页负责英文、中文解释、按钮、发音、练习、进度和无障碍信息。
- 原三联知识长图继续用于分享与导出，不直接裁切后塞入学习页。

## 二、交付范围

为 BE 三模块制作并接入 6 张独立 3D 场景图：

| 资产 | 所属模块 | 教学任务 | 触发方式 |
|---|---|---|---|
| 身份桥 | BE① | 看见主语与身份的连接 | 选择“身份” |
| 位置桥 | BE① | 看见主语与位置的连接 | 选择“位置” |
| 状态桥 | BE① | 看见主语与状态的连接 | 选择“状态” |
| 主语换衣服 | BE② | 看见 BE 随主语与时间换形态 | 切换主语或 Today / Yesterday |
| 正在发生 | BE③ | 对比普通动作与 `be + doing` | 选择“看动作过程” |
| 结果状态 | BE③ | 看见 `be + done` 的受作用或结果状态 | 选择“看结果关系” |

不在本轮范围内：实时 3D 模型、自由旋转、视频动画、全套被动语态、否定句、问句、850 词批量配图。

## 三、六张图的画面定义

### 1. 身份桥

小学生位于画面左侧，右侧是书包、课本和可识别的学生身份场景，中间是一座发光的 BE 桥。网页在画面外显示 `I am a student.`，并把 `I / am / a student` 映射到桥的三段。

### 2. 位置桥

小猫与沙发构成清楚的空间关系，猫在沙发上；中间保留 BE 桥的统一视觉母题。网页显示 `The cat is on the sofa.`，突出 `is` 连接主体与位置。

### 3. 状态桥

一个开心的孩子与太阳、笑脸或舒展姿态形成状态线索；BE 桥连接人物与 `happy`。网页显示 `You are happy.`。

### 4. 主语换衣服

一个统一的 BE 小角色位于中心，周围是代表 `I`、`he / she / it`、`you / we / they` 的儿童或物体角色。图片不写入 `am / is / are / was / were`；这些词由网页覆盖层根据选择动态显示，避免为每种变化重复出图。

### 5. 正在发生

男孩正在读书，使用翻动的书页、身体姿态和轻微动作轨迹表达过程正在展开。网页在图片外对比 `He reads.` 与 `He is reading.`。

### 6. 结果状态

画面同时提供两个可辨识的小场景：妈妈完成蛋糕，以及已经破掉的窗户。网页分别显示 `The cake was made by my mother.` 与 `The window is broken.`，帮助孩子区分受动作作用与结果状态。

## 四、视觉规范

- 风格：儿童友好、简洁的 3D 黏土或软质玩具质感，与 3D 知识图卡 Pro 保持同一视觉语言。
- 色彩：浅蓝、柔紫为主，身份、位置、状态可使用少量不同强调色。
- 构图：横向 `4:3`，主体明确，背景简洁，保留网页叠加标注所需留白。
- 文本：图片内部不嵌入英文、中文、按钮或解释；所有文字由网页渲染。
- 一致性：六张图的人物比例、光线方向、圆角语言、阴影强度和材质统一。
- 安全性：不使用品牌角色、真实儿童照片或具有版权风险的现成卡通形象。

## 五、数据结构

仅在现有 `website/v2-data.js` 的 `BE.interactive` 模块内增加可选视觉描述。示例：

```js
visual: {
  asset: 'assets/be/identity-bridge.webp',
  alt: '学生通过 BE 桥连接到 student 身份',
  placement: 'module1-identity'
}
```

每个视觉对象必须包含：

- `asset`：本地图片相对路径。
- `alt`：描述英语关系的替代文字，不只描述装饰。
- `placement`：稳定的模块位置标识，用于渲染映射和测试。

本轮不建立通用媒体管理器，不修改其他 V2 节点。BE 验证稳定后，再根据真实数据提炼 `WordLessonSpec.visuals`。

## 六、页面与交互

### BE①

模块标题下显示当前场景图。点击“身份 / 位置 / 状态”时，图片、桥图、关系问题、例句、解释和发音目标同步更新。一次只显示一张图，避免孩子同时处理三个场景。

### BE②

显示一张“主语换衣服”主场景。选择主语或 Today / Yesterday 时，图片保持稳定，网页覆盖层切换 `am / is / are / was / were`，帮助孩子理解“核心意思不变，外形随主语和时间变化”。

### BE③

“看动作过程”显示正在发生图；“看结果关系”显示结果状态图。图像与解释、例句同步切换，判断题保持原有流程。

### 响应式布局

- 桌面端：图片与当前解释可左右排列，但学习顺序仍为图 → 关系 → 例句 → 操作。
- 移动端：图片全宽置顶，控件与解释单列排列，不出现横向滚动。
- 所有交互按钮保持至少 44px 点击高度，选中状态不能只依赖颜色。

## 七、图片加载失败处理

- 图片加载失败时隐藏破损图片图标，显示现有 CSS/语义桥图和 `alt` 内容。
- 加载失败不得隐藏例句、发音、匹配、判断或完成状态。
- 不依赖远程 CDN；全部使用项目内本地资产。
- 未配置 `visual` 的旧节点继续走原有渲染，不出现空白占位。

## 八、工程边界

- 不修改 BE 已确认的教学结论、例句、错误反馈和完成条件。
- 不修改 V1 `progress.words.be`；BE 模块进度仍只使用 `progress.v2.be`。
- 不重构无关页面，不修改其他 12 个 V2 节点。
- 不覆盖 ON、Culture、Camera 等已有未提交改动。
- 不把图片转成 base64 写入 JavaScript；图片以独立本地文件管理。

## 九、测试与验收

### 自动检查

- 6 个视觉对象的数据字段完整，路径、替代文字和位置标识有效。
- BE① 三个选择分别映射到正确图片。
- BE② 主语与时间切换不会请求额外图片，也不会破坏 form 逻辑。
- BE③ 过程与结果切换映射到正确图片。
- 图片失败时保留可读回退内容和全部学习控件。
- 现有 V1、Culture、Camera、World、WordImage、Sentence 及其他 V2 测试继续通过。

### 浏览器验收

- BE 深度学习页真实显示 BE①、BE②、BE③，而不是只显示旧的通用文字区块。
- 桌面端和 375px 移动端均能看到清晰图片、完成全部操作且无横向溢出。
- 图片切换、发音、配对、时间切换和判断题可连续完成。
- 键盘可操作所有选择；图片均有有效替代文字。
- 图片请求全部成功；控制台无与本功能有关的错误。

## 十、完成定义

只有同时满足以下条件，才可称为“BE 3D 配图母版完成”：

1. 6 张风格统一的本地 3D 场景图已生成、审核并接入。
2. 三模块在真实页面渲染，图片与当前教学状态同步。
3. 图片失败时学习流程仍完整可用。
4. 自动测试、语法检查、桌面和移动端视觉验收全部通过。
5. 未改变既定教学逻辑，未影响其他学习模块及既有未提交改动。
