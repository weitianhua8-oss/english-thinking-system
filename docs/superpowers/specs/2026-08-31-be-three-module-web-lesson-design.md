# BE 动词三模块网页知识课母版设计

**状态：** 已由用户确认，进入实施计划阶段。
**范围：** 仅扩展现有 V2 的 `BE` 词条；其他词条、V1 复习、850 词表与路由保持不变。

## 目标与边界

BE 先作为唯一试点，在既有“快速理解 / 深度学习 / 知识网络 / 复习反馈”外层中，把“深度学习”升级为三个连续互动模块：

```text
BE① 状态连接器 → BE② 主语与时间换形态 → BE③ 结构扩展与避坑
```

BE 不是动作发动机；它把主语连接到身份、位置、状态或过程。学习路径为“看画面 → 理解核心 → 操作变化 → 听英语 → 自己判断 → 做题验证”。

模块进度只存放在 `progress.v2.be`，绝不写入或覆盖 `progress.words.be`；页尾现有“再来一次 / 不太确定 / 理解了”仍是唯一影响复习间隔和掌握度的入口。

## 内容模型

仅在 `website/v2-data.js` 的 `be` 节点增加可选 `interactive`：

```text
interactive
├── module1：identity / location / state 分支、图解文案、例句与音频键
├── module2：主语组、现在/过去 form、配对题、时间切换原型句
├── module3：定位卡、be + doing / be + done 对比、判断题
└── completion：三个模块的完成条件与总结
```

所有可见解释、例句、反馈、视觉替代文字和音频键均来自已确认的 BE 内容：`data/golden-learning-layers.v1.json`、`content/Level1_50个骨架词完整教程.md` 和 `visual/3d-card-standard/BE-reference/STYLE_GUIDE.md`。缺少完整模块数据时，页面显示“该模块准备中”，不渲染半成品控件；没有 `interactive` 的节点继续使用原有静态 V2 页面。

## 三模块

### BE①｜状态连接器

中心图解固定为“主语 / 谁？ → BE 桥 → 身份 / 位置 / 状态”。默认身份；切换任一分支时，同步更新图解、中文关系问题、英文句、简短解释与可播放句子。首版使用本地 CSS/SVG 语义图形，不引入远程资源。

### BE②｜主语换衣服，时间换形态

学习者选择 `I`、`he / she / it`、`you / we / they`，观察 `am / is / are`；再通过 Today / Yesterday 观察 `was / were`。配对采用可键盘完成的点选方式，错误只给当前题提示、允许重试，不影响 V1 掌握度。

### BE③｜结构扩展与避坑

提供四块内容：身份/位置/状态/时间定位；普通动作与 `be + doing` 的过程镜头；`be + done` 的受动作作用/结果状态；以及“正确 / 需要修改”的判断题。错误题第一次只给方向性反馈，重试后再显示完整图解原因。本轮不扩展完整被动、否定、问句或时态体系。

## 无障碍与兼容

- 所有选择均为带可读标签的原生 `button`，并以 `aria-pressed`、文字、位置和颜色共同表达状态。
- 图解始终保留图形、英文短语、中文关系提问和 `aria-label`；375px 时改为单列且不出现横向溢出。
- 浏览器没有语音能力时，控制显示不可用状态，阅读和练习仍可完成。
- 刷新后只恢复 `progress.v2.be` 的模块完成状态和最近位置；既有 `culture`、`camera`、`world`、`wordImage`、`sentence` 记录和 V1 `words` 记录必须原样保留。

## 验收

在 BE 的深度学习层完成三个模块，能看见同步图解、正确的 form 与针对当前题的反馈；其他 12 个 V2 节点维持不变。全量 Node 测试、两份 JavaScript 语法检查和 375px 样式契约均通过；桌面、移动端和键盘可完成所有流程。BE 稳定后才以真实 `interactive` 数据提炼通用 `WordLessonSpec`。
