# V2 知识网络思维导图设计

## 目标

将 V2 的“知识网络”桌面页由三栏工作台升级为可探索的左到右树状思维导图，让学习者先看到知识的层级和关系，再在右侧理解每条连接为什么成立。

本次只改 V2 知识网络页面的呈现与交互状态，不修改 850 词词库、170 天计划、V1 课程/复习/进度，也不新增或推断任何关系边。

## 用户体验

桌面端采用固定阅读顺序：

```text
认知系统 → 当前词（核心本源） → 真实关系分支    |    关系解释面板
```

- 左栏：认知系统入口。选择系统后定位系统中的默认或已选节点。
- 中栏：树状导图。当前词为视觉根节点；右侧分出其真实的上位系统、直接生长、组合关系和易混对比。
- 右栏：关系解释面板。点击一个关系分支后显示该边的名称、解释、目标词核心含义和“继续探索”按钮。
- 初始状态：选中当前词的“核心本源”说明；有关系时不强制预选某一条边。
- 点击关系节点：更新解释面板，不自动跳词。
- 点击“继续探索”或目标词：沿现有 `select-network-node` / `select-network-direct` 状态逻辑进入目标词，并保存已有探索路径。

## 导图节点与关系

中栏只渲染当前 V2 节点经 `explorableRelations()` 验证后的关系。没有解释、目标不存在、类型非法或不可探索的边不渲染。

### 根节点

- 显示单词和 `coreMeaning`。
- 视觉上为深蓝紫渐变，明显大于其他节点。
- 根节点下给出一句 `quick.origin`，使导图不是无语义的连接图。

### 分支节点

每条关系是一个独立、可聚焦的按钮，内容包括：

- 关系类型标签；
- 目标单词；
- 目标词的核心含义；
- 对组合关系保留来源表达，例如 `IN + TO → INTO`。

分支颜色必须表达关系语义：

| 关系 | 色彩 |
| --- | --- |
| 上位系统 | 中性灰 |
| 直接生长 | 青绿 |
| 组合关系 | 蓝紫 |
| 易混对比 | 暖黄 |

不以“同一分类”或“看起来相近”推断分支。所有导图节点都来自现有结构化关系数据。

## 关系解释面板

右栏始终可见，包含：

- 当前选中关系的类型及说明；
- 目标词与核心含义；
- 该关系的 learner-visible explanation；
- 继续探索目标词的按钮；
- 已选中分支的可视状态。

未选择关系时展示当前词的“核心本源”，不使用空白面板或技术性错误文本。没有可探索关系时使用中性提示。

## 响应式行为

- 宽度大于 1180px：左栏系统、中央导图、右栏解释并列。中央导图可以纵向滚动，但不制造页面横向滚动。
- 宽度不超过 1180px：知识网络提前切换至既有 `systems → nodes → detail` 单面板状态，避免侧栏和主内容压缩树状导图。`detail` 中显示当前词的真实关系列表和已选关系解释；不强行压缩桌面导图。
- 全站其他页面仍在 900px 才切换原有移动布局；1180px 断点只限定知识网络工作台。
- 触控按钮最小高度 44px；长中文说明正常换行；英文结构不被逐字截断。

## 数据与状态边界

新增一个仅用于网络页面的 UI 状态 `networkRelation`：

- 值为已选关系的稳定关系键，或 `null`。关系键由 `[type, target, label, explanation]` 生成，因而同一目标词的两条不同关系也能分别选择；
- 切换系统、节点、直接打开节点或返回上一步时重置为 `null`；
- 关系按钮只更新该状态；
- 所有现有探索路径、系统选择和移动端步骤规则保持原样。

渲染前再次防御性验证已选关系仍存在。若数据改变导致失效，则回退到当前词核心本源，不抛错。

## 实现范围

仅限：

- `website/app.js`：纯状态辅助函数、网络渲染、现有事件委托中的关系选择动作；
- `website/styles.css`：导图与响应式专用样式；
- `website/app.test.js`：关系选择、渲染、状态重置与 V1 回归测试。

不修改：`website/data.js`、`website/v2-data.js`、`website/v2-network.js`、`website/index.html`、词库、学习计划、进度存储格式。

## 验收与验证

1. 桌面 DOM 同时含系统入口、树状根节点、关系分支和解释面板。
2. 关系分支只来自当前节点的 `explorableRelations()`。
3. 选择关系后只更新解释状态，不破坏探索路径；进入目标词后重置关系选择。
4. 不存在/非法关系安全回退到核心本源。
5. 关系色彩符合四类语义，且 CSS 选择器命中实际 DOM。
6. 窄屏保持既有单面板状态与无横向溢出。
7. 非 V2 词条、V1 复习、进度、课程和数据完整性回归测试持续通过。
