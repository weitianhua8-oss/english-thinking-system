# 英语思维850｜Level 1 学习系统 V1 设计说明

## 1. 目标与范围

本次交付把现有离线原型升级为可实际学习的 Level 1 网站产品，面向零基础或基础薄弱的成人学习者。

交付范围固定为 50 个骨架词；网站可直接双击 `website/index.html` 离线使用。首版不做登录、云同步、支付、多人协作、850 词完整课程或真实交易类功能。

学习目标是让用户从“核心画面和关系”理解单词，而不是依赖中文释义死记。

## 2. 已确认的产品方案

采用单页离线网站方案，保留现有 `website/` 目录结构。页面由 JavaScript 切换，无需服务器和构建工具。

数据来源：

- `data/level1_lessons.json`：50 个完整词条内容，是课程正文的唯一来源。
- `data/vocabulary_850.json`：只取前 50 个词的知识树元数据。
- `data/learning_plan_170days.csv`：Level 1 的前 10 个学习日，每天 5 词。

网站只打包 Level 1 所需数据；850 词库不在 V1 页面显示
，避免误导用户以为后续内容已经完成。

## 3. 页面与交互

### 今日学习

- 自动定位到当前尚未开始的 5 词学习日；用户也能从学习进度选择 Day 1–10。
- 每日 5 张词卡展示单词、所属知识系统和一句话本源。
- 点词卡进入词条详情；词条底部提供“不会 / 模糊 / 懂了”三个学习反馈按钮。
- 三个反馈都会记录本次学习时间并排入复习队列：不会=掌握度 1、模糊=2、懂了=3；每次可在词条内继续升至 4。

### 词条详情

固定展示：单词、Lesson 编号、核心画面、底层逻辑、高频例句、易混对比、记忆钩子、关联词。

“核心视觉卡”首版使用课程已有的 `card` 文本作为可读视觉线索，不伪造或依赖外部图片。后续可按 3D 图卡规范替换为本地图片。

### 今日复习

- 默认显示 `nextReview <= 今天` 的词；没有到期词时给出明确提示和下一次复习时间。
- 卡片正面显示英文词和视觉线索，点击/按“查看答案”翻面，显示本源、一个例句与关键对比。
- 完成复习后记录反馈并按新的时间间隔更新 `nextReview`。

### 50 词库、知识树与易混对比

- 词库只提供 50 词搜索、知识系统筛选和掌握状态筛选。
- 知识树按 5 个系统展示 50 个节点与完成数，点击进入词条。
- 易混对比提供已定义的关系组（如 `go / come`、`in / on / at`），可跳转到相关词。

### 学习进度

- 显示已开始、能说画面、能区分、能使用四档统计（对应 1–4）。
- 显示今天到期复习数、连续学习天数、10 个学习日完成情况。
- 提供“清空本机学习进度”按钮，点击时二次确认。此操作只删除本浏览器的本项目数据。

## 4. 本地学习数据

数据储存在浏览器 `localStorage` 的单一键 `english850_level1_progress_v1`，格式如下：

```json
{
  "words": {
    "I": {
      "mastery": 3,
      "lastSeen": "2026-08-12T10:00:00.000Z",
      "nextReview": "2026-08-13",
      "history": ["understood"]
    }
  },
  "studyDates": ["2026-08-12"]
}
```

复习间隔：掌握度 1 为 1 天、2 为 3 天、3 为 7 天、4 为 14 天；掌握度 4 的连续正确复习使用 30 天。错误或“不会”重置为 1 天。数据异常、旧版本或存储不可用时，网站回退为空学习档案并在页面显示简短提示，不阻塞课程浏览。

## 5. 文件边界

| 文件 | 职责 |
| --- | --- |
| `website/index.html` | 页面骨架、导航和无脚本提示 |
| `website/data.js` | 仅包含 50 词、10 天计划、词条课程与易混关系组 |
| `website/app.js` | 页面渲染、筛选、学习/复习交互、本地存储、日期计算 |
| `website/styles.css` | 桌面优先、手机适配的视觉与交互状态 |
| `website/app.test.js` | 抽取出的纯逻辑（复习日、反馈结果、筛选）自动测试 |

为保证离线运行，`app.js` 会以浏览器全局方式暴露少量纯函数给测试环境使用；不增加第三方依赖。

## 6. 错误处理与边界

- 若词条关联词超出 50 词，显示为不可点击标签，不弹出未完成课程提示。
- 若当前词没有课程内容，列表不展示该词；这在 V1 正常数据中不应发生。
- 所有文字由课程数据提供，渲染前做 HTML 转义，避免数据中的特殊字符破坏页面。
- 移动端在 900px 以下折叠侧栏为顶部导航；按钮尺寸保持可点击。

## 7. 验收标准

1. 双击 `website/index.html` 能打开，不依赖网络。
2. 50 个词均可从今日学习、词库或知识树进入完整详情。
3. 任一学习反馈会更新词条掌握度，并在刷新后保留。
4. 模拟到期的词可出现在复习页，卡片可翻面并能记录新反馈。
5. 搜索、知识系统筛选、掌握状态筛选与易混词跳转可用。
6. 进度页的统计与本地数据一致，清空功能只影响当前浏览器。
7. 自动化测试覆盖复习间隔、反馈更新、到期筛选与课程日分组；HTML/JavaScript 基础校验无语法错误。

## 8. 已知限制与后续

- 本地存储清除、无痕窗口或更换浏览器会丢失学习进度；这是离线无账号版本的明确边界。
- V1 先以文字视觉线索代替 3D 图片；图卡资产准备后可逐词替换，不改学习数据结构。
- 850 词扩展应在体验验收后进行，并复用本设计的数据和交互规则。
