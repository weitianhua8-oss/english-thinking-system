# 英语思维词条 Skill｜统一规范

## S级完整模板
1. 单词 / 词性 / 发音
2. 一句话抓住本源
3. 核心动态画面
4. 底层逻辑
5. 含义树：从一个本源向外生长
6. 高频结构：优先解释“核心词 + 空间/状态词”
7. 高频生活例句
8. 易混词：用画面差异对比
9. 常见误区：阻断中文直译
10. 记忆钩子
11. 知识树连接
12. 3D图卡提炼

## A级模板
保留 2/3/4/6/7/8/10/11/12，控制篇幅。

## B级模板
核心画面 + 场景 + 1~2 高频句 + 主题归类；具体名词不做无意义“深挖”。

## 审校红线
- 禁止把“一串中文释义”冒充底层逻辑。
- 禁止为所有词强行找神秘词源故事。
- 图卡不能先于正文逻辑。
- 易混词必须真正可混，不为凑格式而比较。
- 例句优先复用已学词，降低认知负担。
