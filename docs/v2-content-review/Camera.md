# P3 Camera 内容审校记录

## 审校目标

Camera 只训练“面对一个现实画面，先拍谁、再看发生什么、再补一项信息”的观察路径。它不用逐词中译英，也不承担摄影知识、Sentence、Grammar 或多题场景训练的任务。

## 单场景样板

| 项目 | 审校结论 |
| --- | --- |
| 场景 | 图书馆里，一个男孩正在桌边做作业。 |
| 推荐路径 | Focus → Action/State → Object/Relation → Expansion。 |
| 推荐句 | `The boy is doing homework in the library.` |
| 信息增量 | 男孩 → 正在做作业 → homework → in the library；每步只增加一项画面信息。 |
| 合理替代焦点 | 书或图书馆也可成为观察角度；提示其可行，但本样板需要先跟随男孩完成当前路径。 |

## 图片引导边界

- 首屏先显示没有高亮的完整图书馆插画，先看世界，再决定 Focus。
- 本地静态插画负责真实、可观察的图书馆现实画面；透明 SVG overlay 只负责教学聚焦，不再用 SVG 重绘人物、书架或场景。
- 选择男孩、书或图书馆时，overlay 会改变插画内部对应区域的明暗、留白和描边；这不是图外标签或装饰边框。
- 推荐路径上的同一张图按 `Focus → Action → Relation → Background` 改变教学重点：男孩聚焦、手边作业动作提示、男孩与作业对象的关系线、重新强调图书馆环境。
- 图片只服务当前一个图书馆样板，不建立新场景库、不使用外链图片、Canvas 或动画系统。

## 教学边界

- 不把推荐句说成唯一可表达该画面的英语句。
- 不把其他合理观察角度直接标为“错误”。
- 不讲主谓宾、时态、进行时等复杂语法名称；只说明画面新增了什么信息。
- 不把完成状态写入 V1 单词、复习队列、掌握度或 170 天计划。

## 后续接口

- World：接住 Camera 已确定的镜头意识，继续看清画面里的现实角色、物品、动作、关系和背景。
- Word Image：从 World 的现实关系中拿出一个英语词的核心画面。
- Sentence：在 World 与 Word Image 之后，从已选定焦点开始，一次补上一项画面信息。
- Grammar：以后解释画面信息变化与标记的关系；当前不开放。
- Scene Training：以后扩展为多场景重练；当前不建立题库或通用训练引擎。
- 每次推荐选择后依次呈现中文观察反馈、英语镜头块和明确下一步；“重新选择焦点”只作为完成后的次级操作。
- 完成后通过“下一站：进入 World”交给已开放的 World；Camera 不把这些英语块讲成完整句法结构，也不直接跳到 Sentence。
