# P3 Camera 内容审校记录

## 审校目标

Camera 只训练“面对一个现实画面，先拍谁、再看发生什么、再补一项信息”的观察路径。它不用逐词中译英，也不承担摄影知识、Sentence、Grammar 或多题场景训练的任务。

## 单场景样板

| 项目 | 审校结论 |
| --- | --- |
| 场景 | 图书馆里，一个男孩正在桌边做作业。 |
| 推荐路径 | Focus → Action/State → Object/Relation → Expansion。 |
| 推荐句 | `The boy is doing homework in the library.` |
| 信息增量 | 男孩 → 正在做作业 → homework → in the library；每步只增加一项画面信息。 |
| 合理替代焦点 | 书或图书馆也可成为观察角度；提示其可行，但本样板需要先跟随男孩完成当前路径。 |

## 教学边界

- 不把推荐句说成唯一可表达该画面的英语句。
- 不把其他合理观察角度直接标为“错误”。
- 不讲主谓宾、时态、进行时等复杂语法名称；只说明画面新增了什么信息。
- 不把完成状态写入 V1 单词、复习队列、掌握度或 170 天计划。

## 后续接口

- Sentence：从已选定焦点开始，一次补上一项画面信息。
- Grammar：以后解释画面信息变化与标记的关系；当前不开放。
- Scene Training：以后扩展为多场景重练；当前不建立题库或通用训练引擎。
- 完成后仅提示 Sentence 当前准备中，不开放其路由。
