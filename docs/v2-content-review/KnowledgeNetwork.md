# 知识网络内容与交互审校记录

## 当前样板

- 当前只制作 `GO` 的完整左→右逻辑导图。
- 根节点是 `GO`；一级分支依次覆盖本源、核心画面、词源提醒、意义生长、使用场景、固定结构、易混对比、避坑、例句和记忆钩子。
- 节点以短句记录，不把词典式长段解释塞进导图。

## 与知识树的边界

- **知识树｜按顺序学**：从知识系统进入词条，按核心画面、逻辑与例句逐层学习。
- **知识网络｜看关联**：从一个词向右查看它和场景、结构、对比、例句之间的横向连接。
- 两页不复制同一套完整内容；知识网络的 GO 样板不意味着已批量覆盖 850 词。

## 视觉与交互判断

- 导图固定使用根节点在左、一级分支向右、当前展开细节继续向右的逻辑阅读方向。
- 一级分支可展开或收起；可点击节点查看补充说明；原生按钮保留键盘焦点与选择状态。
- 手机端不把导图改成普通上下卡片列表，而是在可横向浏览的容器中保留左→右结构。
- 不使用 SimpleMindMap / Simple Mind Map，也不引入外部导图库；以结构化课程数据和站内渲染实现可验证的导图交互。

## 内容边界

- `GO` 是知识网络的首个样板，不自动扩展到 50 词或 850 词。
- 现有 13 个 V2 关系样板继续作为次级探索入口，不被 GO 导图替代或删除。
- 本轮不进入 Grammar、Scene Training 或 Output。
