## 3. V1 已实现的学习产品能力

网页入口：`website/index.html`（离线双击可打开）

### 3.1 已可使用的页面与流程

- 今日学习：Level 1 的 Day 1–10，每天 5 词。
- 课程页：核心画面、底层逻辑、例句、易混点、记忆钩子、关联词。
- 词库：50 个 Level 1 词的搜索、系统筛选、掌握度筛选。
- 知识树：按 Level 1 的 5 大系统查看词条与已学数量。
- 易混对比：进入对比词的课程。
- 今日复习：到期词翻卡后给出学习反馈。
- 学习进度：掌握度 1–4、待复习数量、连续学习、按 Day 查看完成量。
- 重置本机档案：两次确认后删除本机学习进度。

### 3.2 复习与本地存储

- 反馈：`再来一次` / `不太确定` / `理解了`。
- 复习间隔：1 / 3 / 7 / 14 / 30 天。
- 存储：浏览器 `localStorage`，键名为 `english850_level1_progress_v1`。
- 不登录、不联网、不提供云同步；换浏览器、无痕模式或清理网站数据会丢失进度。

### 3.3 V1 产品边界

- V1 本体并不是 850 词完整网页课程，而是已经可用的 **Level 1 50 词学习闭环**。
- V1 的“核心视觉卡”目前是可读文字视觉线索；不是实际图片图卡。
- V1 主线应保留为稳定版本，后续产品实验不要直接覆盖。

### 4.1 三层学习工作台

V2 样板词进入新的课程学习工作台：

| 层级 | 已实现内容 |
| --- | --- |
| Layer 1｜快速理解 | 核心画面、核心意义、一句话本源、典型例句、记忆钩子 |
| Layer 2｜深度学习 | 底层逻辑、成组场景（标题/解释/例句）、高频结构、中文易错点、学习建议 |
| Layer 3｜知识网络 | 当前词所属系统、真实关系、可进入的关联节点 |

- 课程页有快速理解 / 深度学习 / 知识网络三个切换按钮。
- 打开新词时默认回到快速理解。
- V2 样板外的词（如 `GO`）仍走原 V1 课程页，不会被错误套进样板工作台。
- 课程学习反馈、返回词库、返回顶部仍保留。

### 4.2 已完成的 V2 样板知识点：13 个

| V2 认知系统 | 样板词 / 结构 |

| 空间关系 | AT、ON、IN、TO、INTO |

### 4.3 知识网络与思维导图

知识网络遵循四类关系，且每条关系都必须有学习者可见的解释：

| 关系类型 | 含义 | 导图颜色 |
| --- | --- | --- |
| 上位系统 | 词属于哪个认知系统 | 中性灰 |
| 直接生长 | 从核心本源自然长出的结构 | 青绿 |
| 组合关系 | 核心结构组合形成新意义 | 蓝紫 |
| 易混对比 | 同一场景容易选错的不同镜头 | 暖黄 |

当前 V2 知识网络页已实现：

- 宽度大于 1180px：左侧认知系统 → 中间当前词根节点及真实关系分支 → 右侧关系解释面板。
- 点击关系分支只更新解释；点击“继续探索”才进入目标词，并保存探索路径。
- 同一目标词的不同关系可以分别选择。例如 `IN + TO → INTO` 与 `IN ≠ INTO` 不会被合并或覆盖。
- 1180px 及以下：切为“系统 → 词条 → 详情”的单面板逐层阅读；详情页仍可直接切换当前词的其他真实关系。
- 图数据、关系 API 或节点 API 异常时会安全降级，避免页面崩溃。

### 4.4 V2 已完成的工程保障

- 数据层和界面层分离：关系定义在 `website/v2-data.js`，校验/探索辅助在 `website/v2-network.js`，没有硬编码进 HTML。
- 防伪关系：界面只接受当前节点的规范关系；畸形、伪造、目标缺失或无解释的关系不渲染。
- 动态文本与属性经过 HTML 转义；事件采用 `#app` 单一点击委托。
- 学习进度的异常 localStorage 数据会被规范化或安全回退，避免复习/进度页崩溃。
- 当前自动化测试：**79 项 Node 测试通过**，覆盖数据完整性、课程分支、复习、关系校验、关系选择、导图渲染和响应式 CSS 约束。

## 7. 建议后续路线（供 GPT 规划时取舍）

建议不要同时启动 800 个深度课程、850 图卡和 850 节点知识网络。应按“样板标准 → 小批量验证 → 批量生产”推进。

### 路线 A｜先打磨 Level 1（最稳妥，推荐）

1. 对 Level 1 的 50 词做一次 V2 内容审查，标记 A/B/C/D：可保留 / 补深度 / 重做本源 / 重建关系。
2. 扩展 Level 1 知识网络：先为高价值关系补到 50 词，而不是机械连满所有词。
3. 修正图卡提示词冲突，制作 5 张试验图卡并人工评审。
4. 试验图卡通过后，分批完成并接入 Level 1 的 50 张图卡。
5. 用真实用户体验验证三层课程、导图和复习闭环，再沉淀可复用的内容生产模板。

优点：内容质量最高，风险最小，Level 1 可成为后续 800 词的黄金样板。

### 路线 B｜并行推进 Level 2 小批量（速度与质量折中）

在路线 A 的 Level 1 验收同时，选 Level 2 中 20–30 个高频词做一组“完整 V2 课程 + 关系 + 图卡提炼”试点。只有试点通过后再扩大到剩余 Level 2。

优点：能更早验证 V2 模板能否扩展；风险是内容审核工作会变多。

### 路线 C｜先完成 170 天网页路线图（产品覆盖优先）

把既有 170 天 CSV 接进网页，使 850 词可按 Day 1–170 浏览，但明确标注哪些词暂未有深度课程。课程页对未生产词仅显示受控的“基础词条”，不能伪装成英语思维深度课。

优点：产品范围看起来完整；风险是容易让用户误以为 850 词内容质量均已完成，因此不建议先做。
