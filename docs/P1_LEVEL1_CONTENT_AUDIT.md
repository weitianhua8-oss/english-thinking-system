# P1｜Level 1 50 个骨架词内容审查

## 目标
把 Level 1 从“50 个已有教程”升级为后续 800 词可复用的黄金母版。P1 只审内容质量，不新增产品功能。

## 分级标准
- **A**：核心画面与底层逻辑成立，例句/对比能支撑模型；只需小修即可进入黄金样板。
- **B**：主模型可用，但存在覆盖不足、表述过窄、例句或知识关系需要补强。
- **C**：核心模型有明显过度概括、现代用法遗漏或会误导迁移，需要重写关键部分。
- **D**：核心本源不成立、伪词源/伪统一严重，需重新研究后重做。

> 本轮是“教学模型审查”，不是词源学认证。凡涉及历史词源的内容，后续若要写入课程，应单独查证。

## 第一轮统计

- A：40
- B：9
- C：1
- D：0

这说明 Level 1 的底座总体质量已经较高，不应推倒重做。P1 的重点是修正少数“过度统一”的解释，并把最强的骨架词升级成 A+ 黄金样板。

## P1 修订优先级

### P1-A｜必须先修
1. **they（C）**：重写指代模型，纳入 singular they，去掉“必须多个”的错误限制。
2. **it（B）**：拆分 referential it 与 dummy/structural it。
3. **there（B）**：拆分 locative there 与 existential there。
4. **do（B）**：拆分 lexical do 与 auxiliary do。
5. **take（B）**：避免用“抓住带走”硬解释全部高频构式。

### P1-B｜第二批补强
- have
- turn
- feel
- over

## A+ 黄金样板候选（首批 20）

BE / GET / GO / COME / GIVE / PUT / MAKE / KEEP / BRING / SEE / LOOK / WATCH / HEAR / LISTEN / IN / ON / AT / TO / FROM / INTO

这 20 个覆盖：状态连接、结果触达、视角方向、资源转移、落点、结果生成、维持、感知、点/面/体、路径与边界。它们足以作为后续 800 词内容生产的第一版质量标尺。

## 图卡规范同步问题

Level 1 教程仍有多处“诺诺”作为图卡主体的旧描述。当前项目规则已经改为：**3D 知识图卡不使用固定角色/IP 系统，沿用 BE 动词 3D 图卡视觉模型。**

P1 内容修订时应把“诺诺”统一改成“中性场景主体/人物/物体”，但不删除为了表达语义所必需的人物元素。
