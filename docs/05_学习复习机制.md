# 学习与复习机制

## 每天 5 词
850 ÷ 5 = 170 天。默认学习节奏：
- 新学 5 词
- 复习旧词 10~20 个
- 完成 1 组关系对比

## 单词掌握状态
- 0 未学
- 1 看过
- 2 能说核心画面
- 3 能区分易混词
- 4 能在最小句中使用

## 推荐复习间隔
学习当天 → +1天 → +3天 → +7天 → +14天 → +30天。

## 判断“学会”
不是“看到中文能说英文”，而是：
1. 能用一句中文复述核心画面；
2. 能解释至少一个高频用法为什么成立；
3. 能与最容易混的词做画面对比；
4. 能造一个很短、正确、自然的句子。

## 防止负担过重
S级词允许多次学习，不要求一天吃透；B级具体场景词优先快速建立图像连接。
