# 内容生产与质检 SOP

## 生产顺序
1. 从 850 母词库取词。
2. 判断 S/A/B 规格。
3. 写正文，不先做图。
4. 审核“核心本源”能否解释主要高频用法。
5. 生成图卡提炼稿。
6. 做易混关系卡。
7. 回挂知识树。
8. 添加复习记录。

## 质检五问
- 这是不是中文释义换了个说法？
- 核心画面能否真的画出来？
- 高频用法能否从它自然长出来？
- 易混词差异是不是同一维度？
- 初学者能否用一句话复述？

## 版本策略
- 母词库 ID 固定。
- 解释可以迭代，ID 不变。
- 每个词条记录 `content_version`。
- 图卡必须记录对应正文版本，正文大改时重审图卡。
