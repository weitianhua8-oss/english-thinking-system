# Teaching OS V2｜英语学习教学母架构

## 核心链路

```text
WORLD → SEE → FOCUS → GROW → READ → CREATE → CONNECT → REVIEW
```

这是一条从现实观察走向可迁移表达的学习路径，不是必须在一个页面一次走完的机械八步。每个模块只能承担它需要的步骤，并明确说明进入和离开的接口。

| 阶段 | 学习者动作 | 可见产出 | 不应做什么 | 主要 Gate |
| --- | --- | --- | --- | --- |
| WORLD | 回到可观察的真实情境 | 可指认的人、物、动作、状态、关系或背景 | 从中文逐词倒推英语 | G1、G2 |
| SEE | 看见与任务相关的具体信息 | 一条现实观察 | 先背术语或结论 | G2、G7 |
| FOCUS | 决定这次镜头先拍谁、什么或哪种关系 | 一个明确焦点 | 同时塞入多个任务 | G5、G7 |
| GROW | 从核心画面长出逻辑、用法与边界 | 核心逻辑、意义生长链、反例 | 把孤立释义硬拼成统一解释 | G1、G3、G4 |
| READ | 在真实英语里识别已经理解的关系 | 可读、可解释的表达 | 把阅读变成翻译答案 | G1、G5 |
| CREATE | 自己补出、说出、改写或生成英语 | 可被检查的学习者输出 | 只看标准答案 | G6、G7 |
| CONNECT | 连入其他真实语义关系 | 有解释、可到达的关系边 | 因词性或主题强行连线 | G3、G4 |
| REVIEW | 按掌握证据再次调用 | 复习与再输出记录 | 只按日期机械重复 | G4、G6、G7 |

## Grammar Camera

**Grammar Camera** 是语法教学的核心隐喻：像调整镜头一样，先观察现实中的主体、动作、状态、关系、时间和信息焦点；当学习者已经看见“为什么要这样组织信息”后，才命名相应的语法形式。

> **Meaning First → Grammar Name Later。**

它不否定语法名称；它规定语法名称不能抢在意义、画面和逻辑之前出现。任何 Grammar 课程都必须能说明镜头拍到什么、焦点如何改变、学习者如何以新的画面再表达。

## 与现有样板的接口

| 现有样板 | 主要承担的 Teaching OS 步骤 | 当前边界 |
| --- | --- | --- |
| Culture | WORLD → SEE | 说明同一现实不必逐词翻译，不作文化决定论 |
| Camera | SEE → FOCUS → GROW | 练习选择镜头焦点和逐步组织信息 |
| World | WORLD → SEE | 识别角色、物品、动作、状态、关系与背景 |
| Word Image Pro | SEE → FOCUS → GROW → READ | 用核心画面理解一个词或关系 |
| Sentence | FOCUS → GROW → READ → CREATE | 用信息缺口逐层长成一句表达 |
| Grammar | 应覆盖 FOCUS → GROW → READ → CREATE | 当前为计划中，不能写成已开放能力 |
| Knowledge Network | CONNECT | 只展示可解释的语义关系 |
| Mastery / Review | REVIEW | 目标机制已确定，产品实现另立任务 |

## 课程最低要求

任何新教学对象在进入扩展前，都应能回答：

1. 它从哪一个真实世界或画面开始？
2. 学习者此刻聚焦什么？
3. 核心逻辑如何生长，而不是怎样翻译？
4. 学习者会读到什么真实英语？
5. 学习者最终要自己输出什么？
6. 它与哪些知识形成真实连接？
7. 它如何在后续复习中再次被调用？
