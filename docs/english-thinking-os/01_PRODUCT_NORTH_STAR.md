# 01｜Product North Star

**Status:** Canonical

**Authority:** Project Mission、Product North Star 与长期产品目标的唯一 canonical editing source

## 品牌核心

> **把英语变成看得见的画面。**

英语学习的共同起点是现实：谁、什么、正在发生什么、它们怎样相关。文字、图卡、课程和页面都服务于这个起点。

## 世界观

> **Language ≠ Translation。**

中文与英语可以指向同一个现实，却不必逐词对应。中文解释可以辅助理解，但不能替代英语概念、画面、关系和表达的建立。

## 服务对象

- 英语零基础、低基础学习者；
- 儿童及需要更低认知负荷的初学者；
- 希望从“背中文释义”走向理解、迁移和主动表达的学习者。

## 成功定义

学习者逐步能够：

1. 从现实画面中找出英语表达需要的信息；
2. 用核心画面理解词、关系和语法选择；
3. 解释一个用法如何从核心逻辑自然长出；
4. 推断未直接教过的相近例子；
5. 最终自己说出、补出、改写或创造英语。

## 长期边界

- 不以翻译词表、孤立术语或规则堆砌作为课程主线。
- 不为了“覆盖 850”制造浅层、不可迁移的内容。
- 不把视觉做成装饰；每一张图、每一步交互必须帮助学习者看见意义或关系。
