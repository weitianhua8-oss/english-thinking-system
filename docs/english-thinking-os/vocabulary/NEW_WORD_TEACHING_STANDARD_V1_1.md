## 2. 0–7 教学基线

下列顺序逐项来自已确认基线；右栏只描述各步骤的最小任务，不增加新的教学能力。

| 步骤 | 已确认名称 | 最小执行要求 |
| --- | --- | --- |
| 0 | 词型判断 | 先判断词型，再决定必要的解释深度；不机械填满所有模块。 |
| 1 | 记忆外挂 | 给需要记忆辅助的词提供入口；提示与语言事实分开，明确记忆钩子不等于词源。 |
| 2 | 核心画面 | 建立与目标义项一致的画面；不强行用一个万能画面覆盖所有义项。 |
| 3 | 核心结构 | 呈现目标词性和义项所需的结构与使用条件。 |
| 4 | 意义生长 | 呈现必要的现代语义分支及联系，不把教学解释当历史词源。 |
| 5 | 易混对比 | 对需要辨析的词，在明确语境和统一维度上比较使用边界。 |
| 6 | 真实场景 + 高频搭配 | 以高频、自然场景和搭配支持使用，避免罕见义挤占重点。 |
| 7 | 压缩总结 + 输出测试 | 压缩关键认识，并设置至少一个可观察的表达或选择任务。 |

词型分类细节以现行课程真源为准；本标准不将其数据字段或后续实现规则倒写成 V1.1 历史字段。

## 3. 后台五项校验

这五项是内容制作时的校验，不要求儿童额外学习五套理论。

| 校验项 | 执行动作 | 异常处理 |
| --- | --- | --- |
| 频率 | 优先主要高频义项、场景和搭配。 | 缺依据标待审，不编造频率统计。 |
| 词性 | 核对该义项词性、结构和必要形式。 | 词性/结构不确定时停止发布相应解释。 |
| 语域 | 核对正式程度与典型使用条件。 | 不把特定语域用法说成通用替换。 |
| 语义分支 | 保留必要分支和边界，不制造万能核心义。 | 解释无法覆盖时分支保留，不硬接故事。 |
| 词源 | 仅在可靠且真正有帮助时使用；与记忆外挂分开。 | 无可靠来源就不提供词源解释；联想不得充作历史事实。 |

这里恢复的是原则，不生成新的证据评分、关系类型、数据库合同或准入算法。

## 4. 生产执行与检查清单

**目标：** 让词条可理解、可提取、可使用。

**适用：** 英语思维 850 新词内容生产与复核。

1. 读取现行项目真源与本标准，确认目标词和义项。
2. 先做词型判断及后台五项校验，保留依据与待审项。
3. 按 0–7 基线完成适合该词的必要内容，控制解释负担。
4. 检查画面、结构、场景和例句是否表达一致的关系。
5. 做压缩总结及可观察输出任务，交内容审查。

检查清单：

- [ ] 高频重点清楚，词性和语域有边界。
- [ ] 语义分支没有被万能解释覆盖。
- [ ] 记忆外挂没有冒充词源。
- [ ] 场景、结构、搭配自然且相互一致。
- [ ] 输出任务可观察；未审内容不声称已经通过。

出现来源缺失、事实疑点或冻结规范冲突：标待审并停止相关内容发布，记录原因；不得凭“好记”绕过校验。
