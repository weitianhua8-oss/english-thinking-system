# 英语思维850 · 新单词教学标准 V1.3

**Status:** Canonical / Owner Approved

**Version:** V1.3

**Effective date:** 2026-10-18

**Canonical authority:** 英语思维 850 的单词学习卡八部分教学顺序、内容边界与逐义项质量要求的唯一正文编辑源。

**Supersedes:** [新单词教学标准 V1.1](NEW_WORD_TEACHING_STANDARD_V1_1.md)。V1.1 保留为历史恢复基线，不再用于新单词内容生产或冲突裁决。

## 1. 目的与范围

本标准把单词教学组织为“先看见意义，再理解事实，再建立记忆，再使用和压缩”的八部分路径。目标不是堆砌中文释义、词根或助记技巧，而是让学习者能从一个清楚的画面理解词义、辨别边界，并在真实表达中取用。

本标准只规定新单词学习卡的教学顺序与内容质量；不修改：

- `data/vocabulary_850.json` 的 850 词事实权；
- 课程、网页、schema、进度模型或运行时行为；
- Teaching OS、Grammar Vision 或任何冻结课程规则。

与上位治理或语言事实发生冲突时，标记待审并停止受影响内容发布；不得用本标准静默覆盖其他 canonical source。

## 2. 八部分教学顺序

每个单词学习卡按以下顺序组织。某部分确实不适用时简短说明并略过，不为凑满八段而编造内容；但不得调换顺序。

| 顺序 | 模块 | 最小执行要求 |
| --- | --- | --- |
| 1 | 核心画面 | 先给目标义项对应的真实画面、动作、关系或状态；一句话说明它为什么是本词的核心。不能用万能画面硬包所有义项。 |
| 2 | 词源与结构 | 只呈现经核验且有学习价值的词源、真实构词、词性、形式或使用结构；明确这是历史事实、现代构词事实还是不确定项。没有可靠内容就不硬拆。 |
| 3 | 单词助记 | 从熟词联想、真实词根、场景、谐音、自然字形联想中择优融合，给一条最短、最稳的记忆入口；明确“助记设计”与“词源/构词事实”的区别。 |
| 4 | 核心义项总览 | 按高频优先、由具体到抽象列出必要义项，标出哪些可由核心画面自然生长，哪些是独立分支。 |
| 5 | 意义生长与易混辨析 | 每个义项都回到画面解释其生长路径，并在需要时同一场景比较易混词的边界。 |
| 6 | 母语者高频句型 | 给目标词真实、自然、可迁移的高频搭配和句型；例句服务不同义项或结构，避免只是换名词的重复句。 |
| 7 | 词汇知识网络 | 仅连接真正有学习价值的词族、同源词、场景关系、搭配或对比词；每条连接说明关系，不堆相似拼写。 |
| 8 | 最终记忆锚点 | 用一条简短回放串起核心画面、关键边界、最佳助记和最值得输出的用法，帮助学习者隔天提取。 |

## 3. 单词助记：择优融合与事实边界

### 3.1 选择原则

助记可以融合熟词联想、真实词根、场景、谐音和自然字形联想，但只选择真正提高回忆效果的方法：

1. 先守住正确拼写、标准发音提示和当前目标义项。
2. 优先学习者已熟悉的小词、自然画面和简短故事。
3. 通常只给一个最佳融合方案；仅在主要方案容易串词或不同学习者入口确有价值时补一个备选。
4. 字母形状、谐音或拆分不自然时，宁可不用；不得强行拆字母、凑方法或把所有技巧塞进一课。
5. 儿童场景保持温和、可理解；故事必须能回到该词的拼写或目标义项。

### 3.2 三类信息必须分开

| 标签 | 可以写什么 | 不可以写什么 |
| --- | --- | --- |
| 词源/构词事实 | 经可靠资料支持的历史来源、真实词根、词缀或现代构词关系。 | 把未经核验的拆字、谐音或故事当语言规律。 |
| 助记设计 | 为记拼写、声音或义项而设计的熟词联想、场景、谐音、自然字形联想。 | 说成“这个词真正来自……”或用它证明词源。 |
| 教学意义解释 | 从现代核心画面到现代高频义项的解释。 | 借虚构故事伪造历史发展或统一不相关义项。 |

真实词根可同时作为助记材料，但必须先有可核验的事实说明，再把人为画面另标为“助记设计”。没有可靠词源或构词依据时，保留合适助记即可，不开设词根栏。

## 4. 核心义项总览、意义生长与辨析

### 4.1 义项总览

- 只列高频、当前学习目标需要的义项；避免低频义挤占重点。
- 按具体到抽象或最容易理解的顺序排列。
- 每个义项标明“由核心画面生长”或“独立分支”；后者不强行编造统一故事。

### 4.2 逐义项最小内容

每一个进入“意义生长”的义项都必须包含：

1. **核心画面**：这个义项里看见什么对象、动作、关系或状态；
2. **解释**：它怎样由核心画面生长，或为何应诚实地作为独立分支；
3. **搭配**：至少一个自然的高频搭配、结构或句型；
4. **例句**：一条与该义项和搭配直接对应的自然英语例句，并附中文。

不同义项的例句必须承担不同的语义或句型任务；不能反复套用同一主干句，只替换人名、地点或名词。例句不可靠、搭配不自然或无法解释意义路径时，返回事实核验或删减该义项。

### 4.3 易混辨析

仅选择真正会混淆的词进行比较。每组至少给：同一场景、一个明确比较维度、最小对比例句和一个常见误用边界。没有可靠对比价值时不强加辨析段。

## 5. 高频句型、知识网络与最终锚点

- **母语者高频句型**：优先真实生活中可迁移的搭配、句框和语域；不把单个例句伪装成固定句型。
- **词汇知识网络**：可连接词族、同源词、同场景词、反义/对比词或搭配网络。每条边必须说明“为什么连”，相似字母不是充分理由。
- **最终记忆锚点**：压缩为可复述的一句话或短链，至少包含核心画面、最佳助记和一个最易错边界或高频用法；它是复习入口，不替代前文事实说明。

## 6. 制作与验收清单

1. 确认目标词、目标义项、学习者深度及可核验语言资料。
2. 依八部分顺序制作；不适用部分简短说明，不补造内容。
3. 检查助记、词源/构词事实与现代意义解释是否清楚分层。
4. 逐项检查每个义项是否都有核心画面、解释、搭配和不重复的例句。
5. 检查高频句型与知识网络是否真实、可迁移且不重复义项内容。
6. 用最终记忆锚点回放：学习者能否从画面说出目标义、从词形回到正确拼写或用法。

发布前至少确认：

- [ ] 八部分顺序完整且未调换。
- [ ] 不存在为凑方法的拆字母、假词根或牵强联想。
- [ ] 所有助记设计均未冒充词源或构词事实。
- [ ] 每个已教义项都具备画面、解释、搭配和不重复例句。
- [ ] 句型、搭配、例句和辨析自然，且服务不同学习目标。
- [ ] 词源、频率、词性或语域不确定处已标待审，没有伪装为事实。
