## Problem / Scope

问题：词源研究能提供画面，也可能把有趣故事变成假历史。需要先证明能够记录证据、识别不确定性，并产出可试教的现代用法任务。

范围：十个词的作者侧研究；不是十节完整 Pro 课程，不构成学习效果实验。词库、schema、Runtime、网页、Skill 与冻结课程不变。原始上传材料不复制到公开仓库；仅用自己的文字记录必要的待审主张与纠正结论。

## 方法与来源分工

本轮实际使用 Etymonline（ET）、Merriam-Webster（MW）和 Cambridge Grammar / Dictionary（CG / CD）。各记录将主张直接指向页面及栏目。ET + MW 的一致只记为“两站叙述一致”，不宣称其底层证据互相独立。

OED 保留为后续深入研究入口；本轮未取得可核读的相关全文，不作为已核查来源。部分 Cambridge 直接词条返回 403，未把这些失败访问列为证据；改用可读的 MW 词条。CG 的 few / little 说明及 CD 的 understand / girl 内容已成功检索。

本轮没有付费订阅、批量抓取、API 接入或站点内容镜像。记录采用简短原创释述与链接，不复制整篇词典内容。语料频率未做定量统计；“优先义项”是试教取舍，不宣称完整频率排名。

## 主要发现

1. 历史关系明确，也不必成为主课：few、little 更需要现代数量画面。
2. 来源语言与构词已知，不代表具体生活事件已知：insist 不能因此被定位为战争造词。
3. 权威网站也可能保留不同解释：salary 的具体盐钱叙述需按 MW 的反证保留不确定性，不能投票取多数。
4. 词源网站有助于拒绝错误故事：post 分支、few / five、understand 的字面拼接均构成检查案例。
5. 画面、意义关系、历史演变应分别标记；现代连线可有教学价值，但不能冒充词源关系。

## 后续接入顺序

先由独立 Reviewer 复核证据与现代用法；再试教 harvest、insist、few 三个不同类型样板，比较只有现代场景与增加助记后的理解和迁移表现。附录方案不要求新增课程能力或改动冻结节点。

只有试教证明增加历史内容有帮助，才提出独立 Change Proposal，讨论正式教学字段、审核状态和生成路径。正式课程继续服从 `data/vocabulary_850.json → website/data.js → website/app.js` 的项目方向；这些研究 Markdown 不成为第二份词库真源。
