# 词源证据记录模板（研究用）

**Status:** Reference Only / Reusable research template
**Version:** 0.1
**Date:** 2026-10-08
**示范：** [十词记录](TEN_WORD_EVIDENCE.md)

本模板供作者收集证据，不修改项目 schema，也不替代既有教学标准。复制使用时填写事实；未知写“未确定”，不凑历史背景。

## 来源与主张

| 主张编号 | 自己概括的具体主张 | 来源名称、URL、栏目 | 核查状态 / 不确定性 |
| --- | --- | --- | --- |
| H1 | 历史词形或早期意义 | 不仅贴首页，要指向对应词条 | 有据历史 / 未确定 |
| H2 | 生活环境或语义变化 | 明确来源是否真的支持该细节 | 有据历史 / 未确定 |
| U1 | 现代释义、搭配、语域 | 现代词典或可靠用法材料 | 已核查 / 待核查 |

日期要注明是最早可考用例、某义项的记录时间，还是借入时期；不能统一称“诞生日期”。来源转述其他书籍时注明“经该词典转述”，不冒称读过原书。记录 failed / blocked 访问，但不把失败页面当证据。
