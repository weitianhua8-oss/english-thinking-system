## 可执行的试教方案

先选 harvest（历史场景有用）、insist（构词联想）、few（历史主要用于纠错）三个样板；词库外样本只参加研究试教，不自动进入课程。每次只教一个词的一个目标，约 5–8 分钟是计划预算，不是已测数据。

| 步骤 | 学习者动作 | 作者观察 |
| --- | --- | --- |
| SEE | 看现代场景，说出人物在做什么或数量关系 | 是否先识别画面，不依赖中文词表 |
| FOCUS | 聚焦目标词对应的一个动作 / 关系 | 是否抓住本课唯一新能力 |
| GROW | 在适合的样板加入 20–30 秒助记，或直接换现代场景 | 历史 / 联想是否被误当现代定义 |
| READ | 读一条自拟例句，指出与画面的对应 | 是否理解结构与对象 |
| CREATE | 完成记录中的新情境表达 | 能否迁移，不只复述故事 |

比较方案：使用两份内容等量的版本——A 为现代场景，B 在同一现代场景基础上加入简短历史 / 构词辅助；few 的 B 只增加纠错提示。尽量使用不同但水平相近的学习者，或交错分配不同词，避免同一词先学 A 后学 B 的重复学习影响被误称为词源增益。

记录：即时词义理解、迁移造句、24–48 小时后新句理解，各按 0=错误、1=提示后正确、2=独立正确记录；另记耗时及“把历史当现代词义”的错误。小样本只用于发现问题，不能据此宣布统计意义上的学习增益。

继续采用的条件：关键历史误解为零，且理解 / 迁移不退步；若耗时明显增加而无可观察收益，将历史移到展开层。正式课程接入前由 Owner 结合记录确认。
