# 05｜Mastery Model

## 目标定义

掌握不是“看过一次”或“答对一次”。一个知识点的掌握应逐步积累以下证据：

1. **识别：** 能在现实画面或英语材料中看出目标关系；
2. **解释：** 能用核心画面和逻辑说明为什么这样表达；
3. **迁移：** 能处理一个未直接教过但结构相近的新例；
4. **输出：** 能自己补出、改写、说出或写出相关英语；
5. **保持：** 间隔一段时间后仍能再次调用。

这些证据对应 Quality Gates 中的 G2、G3、G4、G6 与 G7。

## 冻结方向

> **用户自选新词数量 + 掌握度驱动复习。**

用户应能按自己的可承受量选择新词数量；复习应主要由掌握证据与遗忘风险驱动，而不是只按固定日期机械重复。

## 当前实现与目标的差别

| 项目 | 当前事实 | 目标方向 | 本文档的处理 |
| --- | --- | --- | --- |
| 每日新词数量 | 170 天计划以 5 词/天为既有排程 | 用户可选择适合自己的新词数量 | 不在本次文档 Reset 修改代码或排程 |
| 复习 | V1 已有掌握度与间隔节点 | 增加更完整的掌握证据驱动 | 需要单独 T3+ 任务设计数据兼容与验收 |
| 数据兼容 | V1 使用 `english850_level1_progress_v1` | 新机制必须兼容读取旧数据 | 未经测试不得改写或迁移旧档案 |

任何复习产品改造必须先通过教学 Gate，再完成 V1 进度隔离、数据兼容、回归测试和 Owner 验收。
