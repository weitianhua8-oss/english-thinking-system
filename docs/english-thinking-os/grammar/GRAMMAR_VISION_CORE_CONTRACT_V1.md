# Grammar Vision Core Contract V1

**Status:** Canonical / Adopted

**Owner:** Project Owner

**Scope:** 仅规定 Grammar Vision 的少量跨课程核心教学合同

**Effective date:** 2026-09-25

## 1. Authority Boundary

本文件只定义 **One New Variable** 与 **Seed → System → Return**。教学母架构、Grammar Camera 与 Meaning First → Grammar Name Later 继续以 [Teaching OS V2](../TEACHING_OS_V2.md) 为 canonical source；本文件不复制或替代它们。

本文件不等于、也不授权：

- Grammar Vision 43 节点正式规格；
- 完整课程顺序；
- 课程节点清单；
- 页面实现规范。

尚未合入主线的 43 节点研究或审计材料继续保持原状态，不因本合同获得 `Canonical`、`Adopted` 或 `FROZEN` 身份。

## 2. Shared Teaching Context

Grammar Vision 的课程仍进入 [Teaching OS V2](../TEACHING_OS_V2.md) 的 `FOCUS → GROW → READ → CREATE` 主链，并遵守 [Learning Objects](../03_LEARNING_OBJECTS.md) 对 Grammar Camera、内容与 UI 的职责边界。下列合同约束的是新认知能力如何进入并完成迁移，不建立第二套 Teaching OS。

## 3. One New Variable

一节 Micro Lesson 默认只新增一个**核心认知变量 / 新能力**。已经掌握的词汇、结构和认知能力可以作为背景。

它用于：

- 控制认知负担；
- 保持因果可解释；
- 让学习者知道这一课到底新学会了什么；
- 让测试能够归因于一个新增能力。

它不表示一节课只能出现一个单词、一个句子或一个语法元素。它控制的是 **new learning variable / new cognitive capability**，不是表面元素数量。

## 4. Seed → System → Return

### Seed

从最简单、可感知、可形成画面的实例进入。

### System

从 Seed 中抽象出可迁移的结构、关系或规律。

### Return

重新回到真实语言场景，让学习者用刚建立的系统理解或生成真实英语。

核心闭环是：

```text
Concrete Experience → Mental Model → Real Language
```

Return 不是重复 Seed。Return 必须验证学习者能否把模型迁移到新的真实语言环境；只复述起始例子，不能证明闭环完成。

## 5. Change and Review

任何改变上述合同含义、边界或验证方式的修改，都必须按 [Change Control](../governance/CHANGE_CONTROL_V1.md) 提交 Change Proposal，并由 Reviewer 按 [Review Protocol](../governance/REVIEW_PROTOCOL_V1.md) 回到本文件逐条比较 semantic change。关键词仍然存在，不代表合同没有被改变。
