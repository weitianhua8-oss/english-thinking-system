# 06｜Teaching Quality Gates

所有新课程、教学 Skill 和学习页面都必须经过以下 Gate。内容丰富不等于教学合格；页面可运行不等于学习路径合格。

## G1 Truth｜真实与准确

**检查：** 语言知识是否准确？是否避免伪词源、伪规则、民族性格解释和过度概括？

**最低证据：**
- 核心解释有可信语言资料、例句或审校依据；
- 写明适用范围与至少一个边界或反例；
- 不把常见倾向写成绝对规律。

**未通过：** 不得发布，不得进入 Golden。

## G2 Image｜明确画面

**检查：** 学习者能否形成一个明确的现实画面、对象、动作、空间或关系？

**最低证据：**
- 能用一句不依赖术语的话描述画面；
- 图、交互或例句至少有一个能指回该画面；
- 画面与所教逻辑一致，不是装饰。

**未通过：** 不得标为 A+，不得进入 Golden。

## G3 Logic｜自然生长

**检查：** 不同用法是否从同一个核心逻辑自然长出，而不是硬解释？

**最低证据：**
- 核心逻辑一句话；
- 至少两条可解释的意义生长路径；
- 明确不适用边界，避免“一个解释包打天下”。

**未通过：** 降回内容审校，不能批量扩展。

## G4 Transfer｜迁移

**检查：** 学完后能否推断一个没有直接教过的新例子？

**最低证据：**
- 一个未直接教过的新情境或表达；
- 学习者选择、解释或产出该例的任务；
- 标准答案说明它怎样由核心逻辑推出。

**未通过：** 不得标为 A+，不得进入 Golden。

## G5 Camera｜镜头链路

**检查：** 能否回到 SEE → FOCUS → GROW → READ → CREATE？

**最低证据：**
- 本模块在 Teaching OS V2 的进入与离开步骤；
- 每一步的学习者动作；
- 若有意省略步骤，说明由哪个相邻模块承担。

**未通过：** 不得宣称是完整学习模块。

## G6 Output｜主动输出

**检查：** 最后是否让学习者真正自己生成英语？

**最低证据：**
- 补全、改写、口头表达、写作或选择后解释中的至少一种；
- 可判断的完成条件；
- 不是只点击“我懂了”或只看答案。

**未通过：** 只能标为理解材料，不能标为完整课程。

## G7 Cognitive Load｜认知负荷

**检查：** 儿童和小白能否逐步理解，而不是“专家觉得完整”？

**最低证据：**
- 每屏一个主要认知动作；
- 术语在意义之后出现；
- 小屏阅读与无图/无语音时的理解退路；
- 清楚标出本步故意不教的内容。

**未通过：** 退回重排信息层级或拆分模块。

## A+ Golden 硬规则

> 一个知识点只要不能通过 G2 Image 或 G4 Transfer，即使内容再丰富，也不能成为 A+ 黄金课程或 Golden Sample。

其他 Gate 也必须记录 PASS / WARNING / FAIL。Owner 只能在明确知道风险时接受 WARNING；G1、G2、G4 的 FAIL 不得通过。

## T3+ 教学任务检查表

| Gate | 结论 | 证据路径 | 未通过处理 |
| --- | --- | --- | --- |
| G1 Truth | PASS / WARNING / FAIL | 内容审校、来源、边界 | 修正知识或停止发布 |
| G2 Image | PASS / FAIL | 核心画面与教学步骤 | 不得 A+ / Golden |
| G3 Logic | PASS / WARNING / FAIL | 意义生长链 | 回到内容大脑重写 |
| G4 Transfer | PASS / FAIL | 新例迁移任务 | 不得 A+ / Golden |
| G5 Camera | PASS / WARNING / FAIL | Teaching OS 映射 | 补入口、出口或相邻模块说明 |
| G6 Output | PASS / WARNING / FAIL | 学习者输出任务 | 增加真实生成动作 |
| G7 Cognitive Load | PASS / WARNING / FAIL | 屏幕顺序与负荷审查 | 拆分或延后信息 |

Builder 提交时填证据；Reviewer 独立验证；Owner 最终决定是否接受 WARNING。
