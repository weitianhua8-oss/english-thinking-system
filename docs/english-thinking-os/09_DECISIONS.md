## 允许变更的证据标准

一条冻结决策只有同时满足以下条件才可改变：

1. 出现可说明问题的教学证据，例如学习者理解失败、迁移失败、负荷过高或语言事实反证；
2. 有至少一个可比较的替代方案或样板；
3. G1 Truth 与 G2 Image 不因改变而退化；
4. Owner 明确确认；
5. 在本文件或新的 ADR 中记录变更原因、影响范围、迁移和回退方式。
