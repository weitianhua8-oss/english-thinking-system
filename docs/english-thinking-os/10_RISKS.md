# 10｜Risks

| 风险 | 影响 | 当前控制 | 解除条件 |
| --- | --- | --- | --- |
| 把样板写成全量能力 | 用户、内容生产与路线判断被误导 | Current State 使用四级状态 | 有可追溯的全量内容、验证和验收 |
| 伪词源、过度概括或文化决定论 | 直接损害教学可信度 | G1 Truth、内容边界与 Reviewer | 有审校证据与反例检查 |
| 有画面但不能迁移 | “好看”不能转化为理解 | G2/G4 A+ 硬门槛 | 新例迁移任务通过 |
| 课程页面认知过载 | 儿童和小白无法完成学习动作 | G7、单屏单任务 | 多宽度与人工学习路径验收 |
| Grammar 方向被误报为已完成 | 造成状态漂移和返工 | 标为“已确认方向，未形成产物” | 完成独立规格、样板、Gate 与验收 |
| 新复习模型破坏 V1 档案 | 已有用户进度丢失或复习混乱 | 本 Reset 不改数据；新任务须兼容测试 | V1 兼容与迁移回归通过 |
| 旧文档继续成为错误真源 | AI 读取过期路线图后偏航 | 入口优先级、历史标识与链接 | Reviewer 确认无冲突入口 |
| 缺少浏览器 E2E 证据 | 自动测试不能证明学习体验 | Owner 人工验收、Node 回归 | 建立稳定 E2E 与多宽度流程 |

任何新风险先写入本文件或当前任务卡，再决定是否继续实施。
