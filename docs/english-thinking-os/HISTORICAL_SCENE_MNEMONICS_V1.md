# 历史生活场景助记规范 V1

**Status:** OWNER ACCEPTED CANONICAL CANDIDATE — mainline-effective after dependency-aware integration
**Owner:** 项目 Owner
**Version:** 1.0
**Date:** 2026-10-08
**Authority:** [CP-2026-003](change-proposals/CP-2026-003-historical-scene-mnemonics.md)
**Scope:** Vocabulary 的记忆外挂选择与历史场景真实性；不替代完整词汇教学标准。

## 1. 核心规则

以后做助记联想，优先寻找单词有可靠依据的历史生活环境。先问：这个词形成或早期使用时，人们身边有什么？他们在干什么？

优先级固定为：**可靠历史场景 → 可靠构词关系 → 视觉 / 动作联想 → 谐音钩子**。

这是作者选择助记材料的优先级，不是要求学习者先上词源课。现代高频词义、核心画面和真实使用仍是教学中心；历史说明只有帮助理解或记忆时才进入课堂。

## 2. 真实性闸门

- “诞生场景”是检索问题，不是每词必填的历史结论。最早可考用例不等于实际造词时间；源语言、进入英语的时期、某个义项出现的时期应分开。
- 不知道准确时代、地点或生活背景时写“未确定”，不得猜测原始社会、农业时代或造词者意图。
- 历史事实必须有可靠词源词典、历史词典或语言学研究支持。记录来源名称、可追溯链接或书目信息、对应义项与支持的具体主张；来源不支持的细节不能补成事实。
- 词源已知不等于故事已知。即使词根可靠，人物、道具和动作也可能只是教学重建。
- 同形词、多源词和不相连的语义分支分别核查，不强串成一条故事。不把现代语义关系说成已经证实的历史演变。
- 字母形状、嘴型、谐音和拟声联想不能单独证明词源。**记忆钩子 ≠ 真实词源**。

每条涉及历史的主张分别采用以下标签；同一画面可以同时含事实与教学重建，须分清边界：

| 标签 | 使用条件 | 写法 |
| --- | --- | --- |
| 有据历史 | 来源直接支持该词或义项的历史信息 | “资料记载……”并附来源 |
| 教学重建 | 根据已核查信息设计的画面，细节未被直接证明 | “根据上述线索，我们可以想象……” |
| 记忆联想 | 用于记忆的字形、动作、谐音或虚构故事 | “可以这样记；这不是真实词源。” |
| 未确定 | 无法核查，或来源有实质分歧 | 说明不确定点；转用现代场景或可靠构词 |

## 3. 场景检索方向

以下是检索与画面设计菜单，不是词源分类事实。词条可以跨场景，也可以没有适合的历史场景。

| 场景方向 | 可观察元素 |
| --- | --- |
| 原始生活 / 狩猎 | 人、动物、足迹、追踪动作 |
| 农业 / 畜牧 | 田地、农具、收获、牛羊 |
| 航海 / 贸易 | 船、港口、货物、交换 |
| 战争 / 防御 | 士兵、盾牌、城墙、守卫 |
| 宗教 / 仪式 | 仪式、祈祷、宗教场所 |
| 工业 / 机械 | 齿轮、动力、机械、厂房 |
| 手工 / 作坊 | 工具、锻造、织布、裁剪 |
| 自然 / 天象 | 日出、风、季节、海潮 |

不得因为一个词今天涉及某场景，就断言它诞生于该时代。抽象词、功能词及来源不明词可直接采用现代高频场景。

## 4. 作者执行流程

1. 先确定所教的现代高频义项、词性、语域与典型用法。
2. 核查该义项的词源、早期意义和生活环境，记录来源与不确定性。
3. 若历史场景可靠且有教学价值，选一个简明画面；否则依次选择可靠构词、视觉 / 动作、必要的谐音。
4. 明确事实、教学重建与记忆联想的边界，再生成核心画面。
5. 解释有依据的意义生长；只属于现代教学模型的连接必须明确标示，不强行统一所有义项。
6. 回到真实例句、易混对比和输出测试。学习者要能用现代英语，不能只记住故事。

这套流程嵌入《新单词教学标准 V1.1》第 1 步“记忆外挂”，不重排用户已确认的 0–7 教学轨，也不把所有词改成词源主导课程。仓库现有 [English Thinking Skill](../../skills/english-thinking/SKILL.md) 的“词源仅为辅助”原则继续适用。

## 5. 学习载体与认知负担

- 儿童 / Lite：只展示有帮助的一幅画、一句解释及必要标签；详细历史和来源留在作者记录或可展开层。
- 成人 / Pro：可展开来源、构词、历史分支和不确定性，仍以现代使用为主。
- Word Image Pro、3D 图卡和知识网络消费同一份已审校内容，不各自发明词源。
- 历史资料相近、画面相似，不足以建立“同源”关系边；词族连接必须单独核查。
- 本规范不新增 JSON 字段，不修改词库、Runtime、页面或学习进度。未来需要结构化字段时另立兼容与迁移任务。

## 6. 验收与边界案例

| 案例 | 合格处理 | 不合格处理 |
| --- | --- | --- |
| 历史背景有据且帮助理解 | 附证据，区分有据部分与场景重建 | 把所有画面细节说成史实 |
| 词源不明 | 标“未确定”，用现代场景帮助记忆 | 给每词硬填古代造词故事 |
| 同形或多源词，例如待核查的 post | 分义项查证后决定是否关联 | 直接宣布“柱子 → 岗位 → 邮政 → 张贴”全为一条历史链 |
| 来源只有字母 / 嘴型联想 | 降为记忆联想，核对现代词义 | 把联想升级为真实词源 |
| 历史义与今天用法不同 | 现代高频义主教，历史可选展开 | 用历史义解释全部现代表达 |
| 儿童需要一次记住一个意思 | 单画面、少文字，验证现代用法 | 强制背时代、源语言与古词形 |

每个新增词条按 [G1–G7](06_QUALITY_GATES.md) 审查：G1 检查来源与标签，G2 检查画面，G3 检查分支与边界，G4 / G6 验证现代场景迁移与输出，G5 保持学习链路，G7 控制负荷。没有证据时不能通过讲故事绕过 G1。

本文件没有认定任何具体单词的词源；示例仅用于规则验收。上传资料是研究输入，未经核查的主张不自动成为项目事实。
