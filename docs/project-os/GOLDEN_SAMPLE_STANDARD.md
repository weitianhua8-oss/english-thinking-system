# Golden Sample 规范

Golden Sample 是 Owner 已确认“这就是正确标准”的可复用样本，用来减少模糊描述与重复返工；它不是灵感收集箱。

## 准入条件

一份样本进入 Golden 前必须同时满足：

1. 有明确来源与版本/提交；
2. Owner 已确认其可作为未来参考；
3. 能写清应复用什么、不能误复制什么；
4. 不含密钥、个人资料、未经许可的素材或错误事实；
5. 具有跨一次任务以上的复用价值。

## 目录与记录

- 可执行样本放 `golden/<sample-id>/`；不可复制的大文件只记录稳定路径、版本和截图。
- 元数据放 `golden/INDEX.md` 或项目已有等价 JSON 索引。
- 一个样本只服务一个清晰用途；不同用途拆为多个样本。

```markdown
## [sample-id]

**用途：** 例如“Level 1 三层学习工作台的内容层级”。
**来源：** 路径、Git commit 或外部授权来源。
**确认人 / 日期：**
**必须继承：** 列出可观察、可检查的特征。
**不可复制：** 仅适用于该页面/内容的元素。
**适用任务：**
**验证方式：** 如何比对。
**状态：** active / superseded / archived。
```

## 使用规则

- 任务卡必须指出具体样本与“继承点”，不能只写“参考之前风格”。
- Golden 优先于抽象审美描述，但不高于 `PROJECT.md`、`RULES.md` 或安全要求。
- 新结果不能仅因“像 Golden”就通过；仍须满足本任务验收。
- 被新的确认样本替代时标为 `superseded`，保留历史原因，不直接删除。
