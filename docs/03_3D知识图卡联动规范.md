# 3D知识图卡联动规范

## 定位
英语思维 Skill 负责“讲明白”；3D 图卡负责“看明白、记得住”。

## 四类图卡
1. **核心词深度卡**：S级词，一词可 2~5 张。
2. **场景词卡**：具体名词，一张卡或主题合辑。
3. **易混对比卡**：同一场景并排呈现差异。
4. **知识树总览卡**：模块入口与复习导航。

## 视觉原则
- 简约留白、轻3D、现代、清晰，不堆字。
- 主视觉先表达逻辑，再装饰角色。
- 箭头、边界、目标点、接触面、路径等空间符号统一。
- 同一对比组必须使用同一视角、同一对象，避免场景差异造成误解。

## 固定内容
标题词 + 一句核心本源 + 核心画面 + 最少例句 + 记忆条。
