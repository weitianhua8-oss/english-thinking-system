# 170-Day Learning Plan

## Recovered baseline
The historical product uses 5 new words per day across 170 days, with spaced reviews at D+1, D+3, D+7, D+15 and D+30.

The later web product also divides the route into six stages:
1. Days 1–20: entry / vocabulary and pronunciation
2. Days 21–40: operation words and direction words
3. Days 41–70: simple sentences and word order
4. Days 71–100: word-form changes
5. Days 101–130: common word groups
6. Days 131–170: situational short texts and retelling

## Current project rule
The 170-day cadence is preserved, but the content layer will be upgraded from translation-first vocabulary study to the English Thinking three-layer model:
- quick understanding
- deep learning
- knowledge network

## Review loop
Each day's learning may trigger review of content learned 1, 3, 7, 15 and 30 days earlier. Future adaptive review may change priority based on mastery, but this baseline remains the deterministic fallback.

## Pending migration
The old schedule contains display-token inconsistencies around parenthetical forms. The canonical 850-item dataset from the web system must be used when rebuilding the day mapping, rather than blindly counting comma-separated strings in the older CSV.
