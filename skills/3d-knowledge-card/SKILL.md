# 3D Knowledge Card Skill — Baseline

## Status
This file establishes the functional rules for the 3D knowledge-card system. The visual reference of record is the previously approved BE-verb 3D card model. The exact visual specification must be recovered from the original BE artifact/reference before being frozen as a detailed style guide.

## Purpose
Convert abstract English logic into a spatial visual explanation. The image is part of the teaching model, not decoration.

## Non-negotiable rule
Do NOT use a character/IP system as the basis of the cards. The card system follows the approved BE-verb 3D knowledge-card model.

## Generation pipeline
English item
→ run English Thinking Skill
→ extract core image / underlying logic
→ determine the best spatial metaphor
→ identify subject/object/state relationships
→ determine direction, path, contact, containment or connection
→ determine information hierarchy
→ apply BE 3D-card visual model
→ generate the card
→ verify that the visual itself explains the English logic

## Visual-semantic principles
1. Meaning before beauty: never generate a pretty illustration first and add English afterward.
2. Spatialize abstraction: use position, direction, distance, container, surface, path, connection and state change when they clarify meaning.
3. One dominant teaching idea per card.
4. Labels support the visual relationship; they must not replace it.
5. Keep the visual hierarchy obvious at a glance.
6. The card should help a learner infer the core logic without memorizing a Chinese translation list.

## Relationship to other systems
- English Thinking Skill decides WHAT the knowledge means.
- 3D Knowledge Card decides HOW one knowledge point becomes visually understandable.
- Knowledge Map decides HOW this knowledge point connects to other knowledge.
- Website decides HOW the learner interacts with all of the above.

## BE reference requirement
The BE-verb card is the canonical visual reference. Before changing layout, rendering language, dimensionality, typography or composition rules, compare against that reference. Do not introduce a new visual style merely for novelty.
