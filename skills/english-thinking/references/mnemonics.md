# 历史生活场景助记规范 V1

**Status:** OWNER ACCEPTED CANONICAL CANDIDATE — mainline-effective after dependency-aware integration
**Owner:** 项目 Owner
**Version:** 1.0
**Date:** 2026-10-08
**Authority:** [CP-2026-003](https://github.com/weitianhua8-oss/english-thinking-system/blob/14a6fbcf38559055c4394b6e0fe5ca6dea02dd08/docs/english-thinking-os/change-proposals/CP-2026-003-historical-scene-mnemonics.md)
**Scope:** Vocabulary 的记忆外挂选择与历史场景真实性；不替代完整词汇教学标准。

## 1. 核心规则

以后做助记联想，优先寻找单词有可靠依据的历史生活环境。先问：这个词形成或早期使用时，人们身边有什么？他们在干什么？

优先级固定为：**可靠历史场景 → 可靠构词关系 → 视觉 / 动作联想 → 谐音钩子**。

这是作者选择助记材料的优先级，不是要求学习者先上词源课。现代高频词义、核心画面和真实使用仍是教学中心；历史说明只有帮助理解或记忆时才进入课堂。

## 2. 真实性闸门

- “诞生场景”是检索问题，不是每词必填的历史结论。最早可考用例不等于实际造词时间；源语言、进入英语的时期、某个义项出现的时期应分开。
- 不知道准确时代、地点或生活背景时写“未确定”，不得猜测原始社会、农业时代或造词者意图。
- 历史事实必须有可靠词源词典、历史词典或语言学研究支持。记录来源名称、可追溯链接或书目信息、对应义项与支持的具体主张；来源不支持的细节不能补成事实。
- 词源已知不等于故事已知。即使词根可靠，人物、道具和动作也可能只是教学重建。
- 同形词、多源词和不相连的语义分支分别核查，不强串成一条故事。不把现代语义关系说成已经证实的历史演变。
- 字母形状、嘴型、谐音和拟声联想不能单独证明词源。**记忆钩子 ≠ 真实词源**。

每条涉及历史的主张分别采用以下标签；同一画面可以同时含事实与教学重建，须分清边界：

| 标签 | 使用条件 | 写法 |
| --- | --- | --- |
| 有据历史 | 来源直接支持该词或义项的历史信息 | “资料记载……”并附来源 |
| 教学重建 | 根据已核查信息设计的画面，细节未被直接证明 | “根据上述线索，我们可以想象……” |
| 记忆联想 | 用于记忆的字形、动作、谐音或虚构故事 | “可以这样记；这不是真实词源。” |
| 未确定 | 无法核查，或来源有实质分歧 | 说明不确定点；转用现代场景或可靠构词 |

## 3. 场景检索方向

以下是检索与画面设计菜单，不是词源分类事实。词条可以跨场景，也可以没有适合的历史场景。

| 场景方向 | 可观察元素 |
| --- | --- |
| 原始生活 / 狩猎 | 人、动物、足迹、追踪动作 |
| 农业 / 畜牧 | 田地、农具、收获、牛羊 |
| 航海 / 贸易 | 船、港口、货物、交换 |
| 战争 / 防御 | 士兵、盾牌、城墙、守卫 |
| 宗教 / 仪式 | 仪式、祈祷、宗教场所 |
| 工业 / 机械 | 齿轮、动力、机械、厂房 |
| 手工 / 作坊 | 工具、锻造、织布、裁剪 |
| 自然 / 天象 | 日出、风、季节、海潮 |

不得因为一个词今天涉及某场景，就断言它诞生于该时代。抽象词、功能词及来源不明词可直接采用现代高频场景。

## 4. 作者执行流程

1. 先确定所教的现代高频义项、词性、语域与典型用法。
2. 核查该义项的词源、早期意义和生活环境，记录来源与不确定性。
3. 若历史场景可靠且有教学价值，选一个简明画面；否则依次选择可靠构词、视觉 / 动作、必要的谐音。
4. 明确事实、教学重建与记忆联想的边界，再生成核心画面。
5. 解释有依据的意义生长；只属于现代教学模型的连接必须明确标示，不强行统一所有义项。
6. 回到真实例句、易混对比和输出测试。学习者要能用现代英语，不能只记住故事。

这套流程嵌入《新单词教学标准 V1.1》第 1 步“记忆外挂”，不重排用户已确认的 0–7 教学轨，也不把所有词改成词源主导课程。仓库现有 [English Thinking Skill](https://github.com/weitianhua8-oss/english-thinking-system/blob/14a6fbcf38559055c4394b6e0fe5ca6dea02dd08/skills/english-thinking/SKILL.md) 的“词源仅为辅助”原则继续适用。

## 5. 学习载体与认知负担

- 儿童 / Lite：只展示有帮助的一幅画、一句解释及必要标签；详细历史和来源留在作者记录或可展开层。
- 成人 / Pro：可展开来源、构词、历史分支和不确定性，仍以现代使用为主。
- Word Image Pro、3D 图卡和知识网络消费同一份已审校内容，不各自发明词源。
- 历史资料相近、画面相似，不足以建立“同源”关系边；词族连接必须单独核查。
- 本规范不新增 JSON 字段，不修改词库、Runtime、页面或学习进度。未来需要结构化字段时另立兼容与迁移任务。

## 6. 验收与边界案例

| 案例 | 合格处理 | 不合格处理 |
| --- | --- | --- |
| 历史背景有据且帮助理解 | 附证据，区分有据部分与场景重建 | 把所有画面细节说成史实 |
| 词源不明 | 标“未确定”，用现代场景帮助记忆 | 给每词硬填古代造词故事 |
| 同形或多源词，例如待核查的 post | 分义项查证后决定是否关联 | 直接宣布“柱子 → 岗位 → 邮政 → 张贴”全为一条历史链 |
| 来源只有字母 / 嘴型联想 | 降为记忆联想，核对现代词义 | 把联想升级为真实词源 |
| 历史义与今天用法不同 | 现代高频义主教，历史可选展开 | 用历史义解释全部现代表达 |
| 儿童需要一次记住一个意思 | 单画面、少文字，验证现代用法 | 强制背时代、源语言与古词形 |

每个新增词条按 [G1–G7](https://github.com/weitianhua8-oss/english-thinking-system/blob/14a6fbcf38559055c4394b6e0fe5ca6dea02dd08/docs/english-thinking-os/06_QUALITY_GATES.md) 审查：G1 检查来源与标签，G2 检查画面，G3 检查分支与边界，G4 / G6 验证现代场景迁移与输出，G5 保持学习链路，G7 控制负荷。没有证据时不能通过讲故事绕过 G1。

本文件没有认定任何具体单词的词源；示例仅用于规则验收。上传资料是研究输入，未经核查的主张不自动成为项目事实。

## 7. 男哥式快记（2026-10-11 Owner 请求补充）

将本节作为第 1 步“记忆外挂”的默认执行方法。这里的“男哥式”指用户要求吸收的短、快、强联想风格；不声称下列分类或新编例子是刘一男的原话或官方方法全集。

### 选择与呈现

- 先快记，再英语思维学透。完成词型判断后，先给一个最容易提取目标词义的钩子，通常 1–3 句；再进入核心画面、结构、意义生长和真实运用。遵循既有 0–7 顺序。
- 按词选择方法，不要求每词堆齐：谐音、词根词缀、近形/对称、象形、拟声、音译外来词、故事场景、引申义串联、复合词拼接/对比辨析。允许中文联想、动作与夸张画面；不机械强拆或硬凑谐音。
- 沿用第 1 节的材料检索优先级；可靠历史场景只有简明且有记忆价值时才选用。查不到有用历史材料时，使用构词或联想，不因缺少词源而省略可用的快记。
- 助记以容易记住和回忆为目标，无须本身是真实词源；语言事实仍须正确。虚构拆分、谐音、字形和故事标为“记忆联想”，真实构词与历史事实按第 2 节标记并核验。不得从联想推出未经核验的同源关系。
- 谐音只作提示，保留正确 IPA；不把中文谐音教成标准读音。不单列“拼写提醒”。


### 把词放回背景环境（2026-10-11 Owner 补充）

- 解释时尽量联系词形成或早期使用的背景环境，或今天真实的使用环境。先回答：谁、在什么地方、面对什么对象或需要、做了什么、为什么在此处用这个词。
- 历史背景有可靠依据且有助理解时，简述当时的生活或使用环境，再连接到今天的目标用法。词源构成已知不等于具体造词现场已知；不知道造词者、年代或动机时，不补写成史实。
- 背景不明或历史材料无教学价值时，直接用一个自然、典型的现代使用场景；至少让学习者明白“什么时候会用这个词”。不要只堆中文释义或孤立词根。
- 教学上重建的古代画面标为“教学重建”，自编助记标为“记忆联想”；现代示例说明为示例，不包装成真实事件。历史事实依据继续执行第 2 节。
- 将背景自然融入快记与核心画面，不机械增加长篇历史模块。用“环境/需要 → 动作或关系 → 目标词义 → 现代例句”建立联系；该链是教学组织方式，不自动代表历史语义演变。

### 部件也要记得住

- 当词根、前缀或后缀值得讲时，不只列“部件 = 中文意思”。为本次实际讲解的每个部件补一个简短画面、动作或联想，再合成整词画面。
- 先核实拆分和该部件在当前词中的作用；只为助记而切出的字母块须明确属于联想，不叫真实词根或词缀。无法可靠拆分的词使用整词场景。
- 控制负担：选一个主钩子，必要时加一个备用钩子；部件助记尽量各一句，不展开低频词表。

### 输出与验收

- 快记输出包含：选定方法、短联想、目标词义连接；使用非事实联想时给一句简短标签。
- 之后必须回到现代英语核心画面、自然例句和至少一个可观察的回忆或表达任务。会复述故事不等于会使用单词。
- 检查四项：钩子能否召回目标义；拆分与联想边界是否清楚；实际讲解的部件是否有助记；是否完成真实场景输出。
- 本节只细化现有记忆外挂，不建立新的字母语义理论、词族数据库、知识图谱关系或课程模块。

### 用户确认助记样例：scrib（2026-10-11）

- 类型：熟词声音联想 + 动作画面；个人记忆联想，不是构词或词源拆解。
- 保留用户原始记忆链：**scrib → rib → write → 写**。
- 声音桥接：这里的 rib 仅作 describe 中 /raɪb/ 片段的视觉提示，再联想到 write /raɪt/；两者共享 /raɪ/，尾音不同。不要把独立单词 rib /rɪb/ 教成 /raɪb/，也不要推广为所有 scrib/script 都这样发音。
- 动作画面：一只手握着尖笔，笔尖在板上划动，留下一行文字。此画面是教学联想，不认定为造词现场。
- 简短输出：**scrib，声音联想到 write，画面就是手握笔写字。**
- 在 describe 的词根助记或用户再问 scrib 如何记时，优先复用这个已确认钩子；其他词条的事实构词关系仍须分别核验。

### 不适用项的输出规则（2026-10-11 用户确认）

- 助记方法判定为不适用时，只输出一行：`序号．方法名称【❌ 不适用】`。
- 不再补充原因、背景说明、安慰性语句、替代联想或画面配音；仅在用户明确追问原因时解释。
- 适用的方法正常展开；不得为了填充不适用项而硬编故事。
- 示例：`5．拟声记忆法【❌ 不适用】`、`6．音译·外来词助记【❌ 不适用】`。
