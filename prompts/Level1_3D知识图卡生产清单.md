# Level 1｜3D知识图卡生产清单

> 统一视觉：沿用已确认的 **BE 动词 3D 知识图卡模型**。简约留白、轻 3D、现代教学感、清晰箭头/路径、少文字、高信息层级。**不使用固定角色/IP 系统**；需要人物时使用中性、无身份的简约人物/场景主体，图卡逻辑优先于装饰。

## 生产原则

- 一张卡只讲一个核心画面；对比词尽量使用同一场景。
- 主卡必须保留：英文词、核心本源短句、空间/动作关系。
- 图卡是正文提炼，不新增与正文冲突的解释。
- S级词优先做“主卡 + 对比卡 + 关系卡”。
- 不为了视觉统一而制造伪语义推导；语法功能和高频固定构式可作为独立分支展示。
- 人物只承担语义角色，不承担品牌角色；不得使用“诺诺”或其他固定人物 IP 作为图卡标准。

## 01｜I
- 核心：I = 说话者把镜头对准自己。
- 视觉：中性说话者居中，胸前 I / SPEAKER 标签。
- 记忆条：I = 镜头对准我自己。

## 02｜you
- 核心：you = 说话者把镜头转向正在交流的对象。
- 视觉：对话站位卡：I → YOU。
- 记忆条：YOU = 镜头对准对方。

## 03｜he
- 核心：he = 指向一个男性第三方。
- 视觉：第三方站位卡：I / YOU / HE。
- 记忆条：HE = 我们正在谈的那个男性第三方。

## 04｜she
- 核心：she = 指向一个女性第三方。
- 视觉：第三方站位卡：I / YOU / SHE。
- 记忆条：SHE = 我们正在谈的那个女性第三方。

## 05｜it
- 核心：it = 中性第三人称支点；可以继续指已知对象，也可以承担结构主语。
- 视觉：双通道：THIS BALL → IT；WEATHER/TIME → IT → STATE。
- 记忆条：IT = 要么接着指“它”，要么把主语位置撑住。

## 06｜we
- 核心：we = I + 其他人，被圈成同一个群体。
- 视觉：群体圆圈卡：I + others = WE。
- 记忆条：WE = 我把自己和别人圈在一起。

## 07｜they
- 核心：they = 第三人称指代槽位，可以指一组，也可以指一个人。
- 视觉：I / YOU 在前；THIRD PERSON 区域显示 1 ↔ many 切换。
- 记忆条：THEY = 对话之外的第三方槽位，可一可多。

## 08｜this
- 核心：this = 指向心理或物理距离“近”的单个对象。
- 视觉：近距离指向卡。
- 记忆条：THIS = 我手边这个。

## 09｜that
- 核心：that = 指向心理或物理距离“较远”的单个对象。
- 视觉：远距离指向卡。
- 记忆条：THAT = 那边那个。

## 10｜here
- 核心：here = 把当前焦点位置标成“这里”。
- 视觉：HERE 地面焦点卡。
- 记忆条：HERE = 镜头脚下这个点。

## 11｜there
- 核心：there 有两个 Level 1 镜头：地点“那里”；there is/are 用于把新对象带进场景。
- 视觉：双卡：HERE ↔ THERE；EMPTY SCENE → THERE IS → NEW OBJECT。
- 记忆条：THERE = 一个是“那边”，一个是“有个东西登场了”。

## 12｜who
- 核心：who = 在“人物槽位”放一个未知问号。
- 视觉：? PERSON 问号人物卡。
- 记忆条：WHO = 人的位置打问号。

## 13｜be
- 核心：be = 把主语连接到它当前所处的身份、状态、位置或过程。
- 视觉：主卡：Subject → BE → State；配套 be/do、be/get 对比卡。
- 记忆条：BE = 状态连接器。

## 14｜have
- 核心：have = 主语与东西、特征、关系或经历建立当前关联。
- 视觉：SUBJECT 中心连接 THING / FEATURE / RELATION / EXPERIENCE 四个端口。
- 记忆条：HAVE = 现在和我“连着”。

## 15｜do
- 核心：do 有两份工作：执行事情；或退到后台做语法支架。
- 视觉：左侧 TASK 执行；右侧 DO 支撑 QUESTION / NOT / EMPHASIS。
- 记忆条：DO = 台前做事，也能后台搭架子。

## 16｜get
- 核心：get = 经过一个过程，最终触达到目标。
- 视觉：五目标主卡 + get in/out/up/back/into/over/through 空间扩展卡。
- 记忆条：GET = 到点；先找目标。

## 17｜go
- 核心：go = 从当前参照点离开，朝别处移动。
- 视觉：HERE → ELSEWHERE 方向卡。
- 记忆条：GO = 从这里走开。

## 18｜come
- 核心：come = 朝说话者、听话者或当前心理焦点靠近。
- 视觉：远处 → HERE；配套 GO vs COME。
- 记忆条：COME = 朝焦点靠近。

## 19｜take
- 核心：take 的原型是主动把某物纳入行动并带走/带着走；高频构式要分支识别。
- 视觉：主图 HAND → OBJECT → MOVE WITH ME；侧栏 COMMON PATTERNS：BUS / TIME / PHOTO。
- 记忆条：TAKE = 先抓主动采取，再认高频构式。

## 20｜give
- 核心：give = 把某物/资源从自己的控制范围转移到别人那里。
- 视觉：控制权转移卡。
- 记忆条：GIVE = 从我这里到你那里。

## 21｜put
- 核心：put = 让一个东西进入指定的位置或状态。
- 视觉：多目标落点卡。
- 记忆条：PUT = 给东西安排一个位置。

## 22｜make
- 核心：make = 通过作用，让一个结果出现。
- 视觉：TASK vs RESULT 对比卡。
- 记忆条：MAKE = 让结果出现。

## 23｜keep
- 核心：keep = 让某物或某状态继续留住，不让它离开或改变。
- 视觉：KEEP 力场卡。
- 记忆条：KEEP = 别让它跑掉、别让状态变。

## 24｜bring
- 核心：bring = 带着人或物，朝“这里/当前焦点”移动。
- 视觉：远处 + BOOK → HERE。
- 记忆条：BRING = 带着东西朝这里来。

## 25｜turn
- 核心：turn = 改变朝向，或从一种可识别状态切换到另一种。
- 视觉：方向旋转 + 状态翻牌；ON/OFF 放在“高频组合”区。
- 记忆条：TURN = 从这个朝向/状态转到另一个。

## 26｜see
- 核心：see = 某物进入视觉范围，视觉结果已经发生。
- 视觉：OBJECT → EYES 结果卡。
- 记忆条：SEE = 东西进了眼睛。

## 27｜look
- 核心：look = 主动把目光和注意力投向某个方向。
- 视觉：EYES → AT → TARGET。
- 记忆条：LOOK = 把眼睛当箭头射过去。

## 28｜watch
- 核心：watch = 把注意力持续放在会变化的对象或过程上。
- 视觉：三帧连续动作卡；WATCH OUT 只作为固定构式小分支。
- 记忆条：WATCH = 眼睛不走，跟着变化。

## 29｜hear
- 核心：hear = 声音进入耳朵，听觉结果发生。
- 视觉：声波 → 耳朵。
- 记忆条：HEAR = 声音进耳朵。

## 30｜listen
- 核心：listen = 主动把听觉注意力投向声音目标。
- 视觉：EAR → TO → SOUND。
- 记忆条：LISTEN = 把耳朵当箭头指过去。

## 31｜feel
- 核心：feel = 通过身体或内在体验获得感受，也可以主动触摸感知。
- 视觉：双通道：COLD/HAPPY → BODY/HEART；HAND → WATER。
- 记忆条：FEEL = 身体/内心有感觉，也可以伸手去感。

## 32｜know
- 核心：know = 信息已经稳定存在于你的认知范围里。
- 视觉：已点亮知识块。
- 记忆条：KNOW = 信息已经在脑子里。

## 33｜think
- 核心：think = 大脑正在处理信息、形成想法或判断。
- 视觉：INPUT → BRAIN → IDEA。
- 记忆条：THINK = 脑子正在加工。

## 34｜in
- 核心：in = 处在一个边界的内部。
- 视觉：透明容器卡。
- 记忆条：IN = 在圈里面。

## 35｜on
- 核心：on = 与表面接触，并处于依附/支撑关系。
- 视觉：接触表面 + ON 接通状态分支。
- 记忆条：ON = 贴上 / 接上。

## 36｜at
- 核心：at = 把地点、时间或目标当成一个点来精准定位。
- 视觉：点定位卡。
- 记忆条：AT = 手指点一下。

## 37｜to
- 核心：to = 朝一个目标点移动或延伸；不定式 to 属语法分支。
- 视觉：起点 → TARGET；右下小标签提示 INFINITIVE TO ≠ SPACE ARROW。
- 记忆条：TO = 空间里先想箭头；语法里要识别不定式分支。

## 38｜from
- 核心：from = 从某个起点、来源或原点出发。
- 视觉：SOURCE → 外部。
- 记忆条：FROM = 箭头从这里长出来。

## 39｜into
- 核心：into = 朝内部移动，并真正跨过边界进入其中。
- 视觉：外 → 穿界 → 内。
- 记忆条：INTO = 箭头钻进盒子。

## 40｜out
- 核心：out = 从内部越过边界，到外面。
- 视觉：内 → 穿界 → 外。
- 记忆条：OUT = 跑出边界。

## 41｜up
- 核心：up = 朝上方，或朝更高、更多、更完整的方向发展。
- 视觉：物理向上 + 数值上升。
- 记忆条：UP = 箭头往上。

## 42｜down
- 核心：down = 朝下方，或朝更低、更少、更弱的方向发展。
- 视觉：物理向下 + 数值下降。
- 记忆条：DOWN = 箭头往下。

## 43｜over
- 核心：over 的空间原型是上方跨越/覆盖范围；be over = finished 作为独立高频分支。
- 视觉：主图“弧线跨越 + 覆盖范围”；右下 `BE OVER → FINISHED` 独立标签。
- 记忆条：OVER = 先抓跨过/罩过；be over 直接识别结束。

## 44｜under
- 核心：under = 位于下方，并处在上方事物的覆盖、控制或压力范围下。
- 视觉：覆盖阴影区卡。
- 记忆条：UNDER = 在下面，被上方罩住。

## 45｜back
- 核心：back = 回到原来的位置、方向、状态或关系。
- 视觉：A → B → A 回旋卡。
- 记忆条：BACK = 回原点。

## 46｜and
- 核心：and = 把两个同方向的信息连接、追加在一起。
- 视觉：A + B。
- 记忆条：AND = 再加一个。

## 47｜but
- 核心：but = 后面的信息让前面建立的预期发生转向。
- 视觉：直路 → 转弯。
- 记忆条：BUT = 逻辑拐弯。

## 48｜or
- 核心：or = 在两个或多个可能之间打开选择分叉。
- 视觉：Y 型分叉路。
- 记忆条：OR = 路口分叉。

## 49｜so
- 核心：so = 前面的情况向前推出一个结果。
- 视觉：CAUSE → RESULT。
- 记忆条：SO = 往前推出结果。

## 50｜because
- 核心：because = 为已经说出的事情向后补上原因。
- 视觉：因果双向对比卡。
- 记忆条：BECAUSE = 往后找原因。

## 优先组合卡

1. **be / get**：在状态里 vs 进入状态。
2. **get / have**：进入结果/到手 vs 当前关系已建立。
3. **do / make**：执行/语法支架 vs 产生结果。
4. **go / come**：离开焦点 vs 朝焦点靠近。
5. **take / bring**：主动采取/典型带离 vs 朝焦点带来。
6. **see / look / watch**：结果 vs 方向 vs 持续过程。
7. **hear / listen**：声音进来 vs 注意力出去。
8. **know / think**：已有信息 vs 加工信息。
9. **in / on / at**：里面 vs 表面接触 vs 点。
10. **in / into / out**：在里面 vs 进去 vs 出来。
11. **from / to / back**：起点 vs 终点 vs 回原点。
12. **and / but / or**：合并 vs 转弯 vs 分叉。
13. **so / because**：向前推结果 vs 向后找原因。
